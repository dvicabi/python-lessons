# חלק א: לומדים לתכנת עם class

## למה אנחנו בכלל צריכים מחלקות?

דמיינו שאתם מפתחים מערכת לניהול בית ספר.

בבית הספר יש 30 כיתות, ובכל כיתה מותקן מזגן חכם.

לכל מזגן יש טמפרטורה משלו, עוצמת קירור משלו ומצב הפעלה משלו.

אפשר ליצור עשרות משתנים נפרדים, אבל מהר מאוד הקוד יהפוך למסובך.

אנחנו רוצים ליצור תבנית אחת של מזגן, ובעזרתה לייצר כמה מזגנים שנרצה.

בדיוק בשביל זה קיימות מחלקות.

### דוגמה ראשונה

```python
class SmartFan:

    def __init__(self, speed):
        self.speed = speed

    def increase_speed(self):
        self.speed += 2


fan1 = SmartFan(5)
fan2 = SmartFan(10)

fan1.increase_speed()

print(fan1.speed)
print(fan2.speed)
```

מה יודפס?

```text
7
10
```

### בואו נבין מה קרה

**`class SmartFan`**

יצרנו מחלקה בשם `SmartFan`. היא משמשת כתבנית ליצירת מאווררים.

**`__init__`**

זו מתודה מיוחדת שמופעלת כאשר אנחנו יוצרים אובייקט חדש. בדוגמה שלנו היא קובעת את מהירות המאוורר ההתחלתית.

**`self`**

מתייחס לאובייקט שעליו אנחנו עובדים כרגע.

לכן `self.speed` שייך למאוורר מסוים ולא לכל המאווררים יחד.

**`increase_speed`**

זוהי מתודה שמשנה את מהירות המאוורר.

**`fan1` ו־`fan2`**

אלה שני אובייקטים שונים שנוצרו מאותה מחלקה.

כאשר הגדלנו את המהירות של `fan1`, המהירות של `fan2` לא השתנתה.

### המשימה שלכם

בכל תרגיל עליכם לבצע שני חלקים:

**משימה א: קריאת קוד**

קראו את התוכנית, הבינו מה כל מתודה עושה וחשבו מה יודפס עבור הקלטים הנתונים.

מומלץ להשתמש בטבלת מעקב ולעדכן את תכונות האובייקט אחרי כל קריאה למתודה.

**משימה ב: כתיבת קוד עצמאית**

כתבו מחלקה משלכם לפי הדרישות, בלי להעתיק את הפתרון מהתרגיל.

### משימה א: קריאת קוד

```python
class SmartFridge:

    def __init__(self, temperature):
        self.temperature = temperature
        self.cooling_score = 5
        self.warnings = 0

    def check(self):
        self.temperature += 1

        if self.temperature >= 10:
            self.cooling_score += self.temperature // 2
            self.warnings += 1

        elif self.temperature >= 6:
            self.cooling_score += self.temperature % 4 + 2

        else:
            self.cooling_score += 1

        self.cooling_score += self.temperature % 3
        self.temperature -= self.cooling_score % 2


temperature = int(input("Enter fridge temperature: "))

fridge = SmartFridge(temperature)

fridge.check()
fridge.check()

print("Temperature:", fridge.temperature)
print("Cooling:", fridge.cooling_score)
print("Warnings:", fridge.warnings)
```

### משימה א: קריאת קוד

```python
class SmartLamp:

    def __init__(self, light):
        self.light = light
        self.lamp_score = 10
        self.energy_score = 4

    def adjust(self):
        self.light += self.light % 5

        if self.light < 40:
            self.lamp_score += 6
            self.energy_score += 2

        elif self.light <= 70:
            self.lamp_score += 3
            self.energy_score += 1

        else:
            self.lamp_score -= 2
            self.energy_score += 3

        self.light -= self.lamp_score % 3
        self.energy_score += self.light // 20

        return self.lamp_score


light = int(input("Enter light level: "))

lamp = SmartLamp(light)

result = lamp.adjust()

print("Light:", lamp.light)
print("Lamp score:", result)
print("Energy:", lamp.energy_score)
```

```python
class ParkingGate:

    def __init__(self, cars):
        self.cars = cars
        self.capacity = 40
        self.accepted = 0
        self.gate_score = 5

    def enter(self, amount):
        if self.cars + amount <= self.capacity:
            self.cars += amount
            self.accepted += amount
            self.gate_score += self.cars % 5

        else:
            self.gate_score += 2

    def leave(self, amount):
        if amount <= self.cars:
            self.cars -= amount
            self.gate_score += amount % 3

        else:
            self.gate_score += 1


cars = int(input("Enter parked cars: "))

gate = ParkingGate(cars)

gate.enter(6)
gate.leave(2)
gate.enter(9)

print("Cars:", gate.cars)
print("Accepted:", gate.accepted)
print("Gate score:", gate.gate_score)
```

### משימה א: קריאת קוד

```python
class SnackCard:

    def __init__(self, balance):
        self.balance = balance
        self.purchases = 0

    def add_credit(self, amount):
        self.balance += amount

    def buy(self, price):
        if self.balance >= price:
            self.balance -= price
            self.purchases += 1
            return True

        return False


balance = int(input("Enter starting balance: "))

card = SnackCard(balance)

first = card.buy(8)
card.add_credit(5)
second = card.buy(12)

print("First:", first)
print("Second:", second)
print("Balance:", card.balance)
print("Purchases:", card.purchases)
```

## מה למדנו בחלק הראשון?

למדנו להגדיר מחלקה, ליצור אובייקטים, לשמור נתונים בתוך אובייקט באמצעות `self`, להפעיל מתודות ולשנות את מצב האובייקט לאורך זמן.

בנוסף ראינו שמתודה יכולה לבצע פעולה בלי להחזיר ערך מפורש, או להחזיר תוצאה באמצעות `return`.

הדבר החשוב ביותר הוא להבין שמחלקה היא התבנית, ואילו האובייקטים הם המופעים שנוצרים ממנה, ולכל אחד מהם יכול להיות מצב שונה.
