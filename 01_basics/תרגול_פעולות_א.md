# חלק א: יסודות הפונקציות ב־Python

## למה בכלל צריך פונקציות?

דמיינו שאתם מפתחים תוכנה לניהול בית ספר.

בבית הספר יש 30 כיתות, ובכל כיתה מותקן חיישן שמודד טמפרטורה.

התוכנית צריכה לחשב את פעילות המזגן בכל כיתה.

האם הגיוני להעתיק את אותו קוד 30 פעמים?

ממש לא!

אנחנו רוצים לכתוב את החישוב פעם אחת, לתת לו שם ולהפעיל אותו בכל פעם שנצטרך.

בדיוק בשביל זה קיימות פונקציות.

### איך מגדירים פונקציה?

```python
def calculate_cooling(temperature):
    cooling = temperature * 2
    print(cooling)

calculate_cooling(5)
calculate_cooling(8)
```

התוכנית תדפיס:

```text
10
16
```

שימו לב לשלושה דברים חשובים:

**1. `def`** מגדירה פונקציה חדשה. היא אינה מפעילה אותה מיד.

**2. `temperature`** הוא פרמטר. הוא מאפשר לפונקציה לקבל ערך מבחוץ.

**3. `calculate_cooling(5)`** היא קריאה לפונקציה. אנחנו מבקשים מ־Python להפעיל אותה עם הערך 5.

### מה ההבדל בין print לבין return?

`print` מציגה מידע על המסך.

`return` מחזירה ערך למקום שממנו קראנו לפונקציה. אפשר לשמור את הערך במשתנה ולהשתמש בו בחישובים נוספים.

לדוגמה:

```python
def calculate_score(num):
    score = num * 3
    return score

result = calculate_score(4)

print(result + 2)
```

התוצאה תהיה 14.

חשוב לזכור: כאשר מתבצעת פקודת `return`, הפונקציה מסתיימת.

# תרגיל 2: מערכת התשלום בחניון 🚗

## הסיפור

בחניון חכם נדרש לחשב כמה כסף נהג צריך לשלם לפי מספר שעות החניה.

הפונקציה מקבלת את מספר השעות, מחשבת את המחיר ומחזירה אותו באמצעות `return`.

לאחר מכן המערכת מוסיפה דמי שירות בסך 2 שקלים.

### משימה א: קריאת קוד

```python
def calculate_parking_fee(hours):

    fee = hours * 5

    if hours >= 5:
        fee -= 6

    elif hours >= 2:
        fee -= 2

    else:
        fee += 3

    fee += hours % 3

    return fee


hours = int(input("Enter hours: "))

fee = calculate_parking_fee(hours)
total = fee + 2

print("Fee:", fee)
print("Total:", total)
```

    water = 20

    if moisture < 30:
        water += (30 - moisture) // 3

    return water

רמזור חכם צריך להחליט כמה זמן יימשך האור הירוק לפי מספר המכוניות שממתינות בצומת.
