# חלק א: לולאות for
## מה קורה כשמערכת צריכה לבצע פעולה שוב ושוב?

דמיינו מקרר שמודד טמפרטורה כל דקה, חניון שבודק כמה מכוניות נכנסו בכל שעה, או רחפן שעובר בין תחנות.

האם הגיוני לכתוב את אותה פקודה עשר פעמים?

בדיוק בשביל זה קיימות לולאות.

לולאת `for` מאפשרת לנו לבצע קבוצת פעולות מספר פעמים, בלי להעתיק את הקוד מחדש.

לדוגמה:

```python
for i in range(1, 6):
    print(i)
```

התוכנית תדפיס את המספרים 1 עד 5.

שימו לב: המספר האחרון ב־`range` אינו נכלל בטווח.

בתרגילים הבאים תגלו איך משלבים לולאות עם קלט, תנאים וחישובים מתמטיים.

# תרגיל 1: המקרר שבודק את עצמו 🧊

## הסיפור

חברה המפתחת מקררים חכמים רוצה לבדוק כיצד משתנה מצב המקרר במשך חמש דקות.

בכל דקה המערכת מדמה שינוי בטמפרטורה ומחשבת מחדש את פעילות הקירור.

המערכת מנהלת שלושה משתנים:

- `temperature` הטמפרטורה המחושבת.
- `cooling_score` מדד פעילות הקירור.
- `warning_count` מספר הפעמים שבהן זוהתה טמפרטורה גבוהה.

החישובים הם הדמיה לימודית ואינם מתארים מנגנון קירור אמיתי.

### משימה א: קריאת קוד

```python
temperature = int(input("Enter temperature: "))

cooling_score = 6
warning_count = 0

for minute in range(1, 6):

    temperature += minute % 3

    if temperature >= 10:
        cooling_score += temperature // 2 + minute
        warning_count += 1

    elif temperature >= 6:
        cooling_score += temperature % 4 + 2

    else:
        cooling_score += 1

    temperature -= cooling_score % 3
    cooling_score += minute % 2

print("Temperature:", temperature)
print("Cooling:", cooling_score)
print("Warnings:", warning_count)
```

|---|---|---|---|

### שאלות חשיבה

1. כמה פעמים הלולאה מתבצעת?
2. מה הערך של `minute` בחזרה האחרונה?
3. האם ייתכן שהתנאי הראשון יתקיים ביותר מחזרה אחת?
4. מדוע החישובים בסוף הלולאה משפיעים על החזרה הבאה?

### משימה ב: כתיבת קוד עצמאית

פתחו מערכת לניהול **מאוורר חכם בחדר מחשבים**.

התוכנית תקלוט טמפרטורה התחלתית, תגדיר משתנים בשם `fan_score` ו־`heat_score`, ותדמה שש מדידות באמצעות לולאת `for`.

בכל חזרה עדכנו את שני המדדים באמצעות פעולות מתמטיות, והשתמשו בתנאים כדי להבחין בין חום גבוה, בינוני ונמוך.

בסיום הציגו את הערכים הסופיים ואת מספר הפעמים שבהן זוהה חום גבוה.

# תרגיל 2: החניון החכם 🚗

## הסיפור

חניון גדול רוצה לנהל את מספר המכוניות שנכנסות ויוצאות.

במקום להפעיל מערכת במשך יום שלם, נבצע הדמיה של שש דקות.

בדקות זוגיות נכנסות מכוניות לחניון, ובדקות אי־זוגיות יוצאות מכוניות.

המערכת מחשבת שלושה נתונים:

- `cars` מספר המכוניות בחניון.
- `gate_score` מדד פעילות שער הכניסה.
- `busy_minutes` מספר הדקות שבהן היו לפחות 35 מכוניות בחניון.

### משימה א: קריאת קוד

```python
cars = int(input("Enter starting cars: "))

gate_score = 4
busy_minutes = 0

for minute in range(1, 7):

    if minute % 2 == 0:
        cars += minute + 1
        gate_score += cars % 5

    else:
        cars -= minute // 2
        gate_score += 2

    if cars >= 35:
        busy_minutes += 1
        gate_score += cars // 10

    elif cars < 15:
        gate_score -= 1

    else:
        gate_score += 1

print("Cars:", cars)
print("Gate score:", gate_score)
print("Busy minutes:", busy_minutes)
```

השלימו:

| קלט | cars | gate_score | busy_minutes |
|---|---|---|---|
| 10 | ? | ? | ? |
| 22 | ? | ? | ? |
| 33 | ? | ? | ? |

### שאלות חשיבה

1. איך התוכנית יודעת אם הדקה זוגית?
2. מדוע השתמשנו בשני תנאי `if` נפרדים באותה לולאה?
3. האם מספר המכוניות תמיד גדל?
4. באילו חזרות עלול המשתנה `busy_minutes` לגדול?

### משימה ב: כתיבת קוד עצמאית

פתחו תוכנית לניהול **מספר הנוסעים באוטובוס**.

התוכנית תקלוט את מספר הנוסעים ההתחלתי ותדמה שמונה תחנות.

בכל תחנה יעלו וירדו נוסעים לפי נוסחאות מתמטיות שאתם בוחרים.

הגדירו גם `ticket_score` ו־`full_stations`.

בכל חזרה השתמשו בתנאים כדי לבדוק אם האוטובוס עמוס, ועדכנו את המשתנים בהתאם.

בסיום הדפיסו את מספר הנוסעים, מדד הכרטיסים ומספר התחנות שבהן האוטובוס היה עמוס.

ודאו שהנוסחאות אינן יוצרות מספר נוסעים שלילי.

# תרגיל 3: התאורה החכמה בבית הספר 💡

## הסיפור

בית הספר מתקין מערכת תאורה שמתאימה את עצמה לאור הנכנס מהחלונות.

המערכת מבצעת בדיקה כל שעתיים, החל מהשעה השנייה ועד השעה העשירית בהדמיה.

בכל בדיקה היא מעדכנת את מדד התאורה ואת מדד צריכת האנרגיה.

המשתנים:

- `light` רמת האור המחושבת.
- `lamp_score` מדד פעילות המנורות.
- `energy_score` מדד צריכת האנרגיה.

### משימה א: קריאת קוד

```python
light = int(input("Enter light level: "))

lamp_score = 18
energy_score = 5

for hour in range(2, 12, 2):

    light += hour // 2 - 3

    if light < 35:
        lamp_score += 4 + hour % 3
        energy_score += lamp_score // 7

    elif light <= 65:
        lamp_score += 2
        energy_score += lamp_score % 4

    else:
        lamp_score -= 2
        energy_score += 1

    light -= lamp_score % 3

print("Light:", light)
print("Lamp score:", lamp_score)
print("Energy score:", energy_score)
```

השלימו:

| קלט | light | lamp_score | energy_score |
|---|---|---|---|
| 25 | ? | ? | ? |
| 50 | ? | ? | ? |
| 80 | ? | ? | ? |

### שאלות חשיבה

1. אילו ערכים מקבל המשתנה `hour`?
2. מדוע הלולאה אינה מתבצעת 12 פעמים?
3. כיצד `range(2, 12, 2)` שונה מ־`range(1, 6)`?
4. מה יקרה אם נשנה את הצעד מ־2 ל־3?

### משימה ב: כתיבת קוד עצמאית

פתחו מערכת לניהול **פנסי רחוב חכמים**.

התוכנית תקלוט רמת אור התחלתית ותבצע בדיקה בכל שלוש שעות, באמצעות `range` עם שלושה פרמטרים.

בכל חזרה עליה לעדכן את רמת האור ואת צריכת האנרגיה.

המערכת חייבת להכיל שלושה מצבי תאורה, לפחות שש פעולות מתמטיות שונות ושני מדדים נוספים שתבחרו.

בסיום הציגו את התוצאות.

# תרגיל 4: שעון הכושר החכם 🏃

## הסיפור

חברה מפתחת שעון חכם שמחשב את מספר הצעדים המצטבר במהלך היום.

לצורך התרגיל נדמה שש שעות פעילות.

בכל שעה השעון מחשב כמה צעדים נוספו, מעדכן מדד אנרגיה וסופר שעות פעילות משמעותית.

המשתנים:

- `steps` מספר הצעדים המצטבר.
- `energy_score` מדד אנרגיה.
- `active_hours` מספר השעות שבהן נוספו לפחות 600 צעדים.

### משימה א: קריאת קוד

```python
steps = int(input("Enter starting steps: "))

energy_score = 12
active_hours = 0

for hour in range(1, 7):

    new_steps = (hour % 3 + 1) * 200

    steps += new_steps

    if new_steps >= 600:
        active_hours += 1
        energy_score += new_steps // 200

    elif new_steps >= 400:
        energy_score += 2

    else:
        energy_score += 1

    if steps >= 2500:
        energy_score += steps % 6

    energy_score -= hour // 3

print("Steps:", steps)
print("Energy score:", energy_score)
print("Active hours:", active_hours)
```

### שאלות חשיבה

1. האם `new_steps` מקבל את אותו ערך בכל חזרה?
2. מה ההבדל בין `steps` לבין `new_steps`?
3. מדוע הבדיקה `steps >= 2500` נמצאת אחרי התנאים?
4. האם הערך ההתחלתי של `steps` משפיע על מספר שעות הפעילות?

### משימה ב: כתיבת קוד עצמאית

פתחו מערכת שמנהלת **נקודות במשחק מחשב**.

המשתמש יכניס את מספר הנקודות ההתחלתי שלו.

כתבו לולאת `for` שמדמה עשרה שלבים במשחק.

בכל שלב השחקן יקבל נקודות לפי מספר השלב, וייתכנו גם בונוסים או קנסות.

הגדירו שלושה משתנים: `score`, `bonus_score` ו־`winning_rounds`.

עליכם להשתמש בתנאים, בשארית חלוקה ובחלוקה שלמה.

בסיום הציגו את הניקוד הסופי ואת מספר השלבים שבהם התקבל בונוס.

# תרגיל 5: רחפן המשלוחים החכם 🚁

## הסיפור

חברת משלוחים משתמשת ברחפנים כדי להעביר חבילות בין תחנות.

הרחפן צריך לעבור שמונה מקטעי טיסה, אבל בכל מקטע הוא צורך אנרגיה מהסוללה.

אם רמת הסוללה יורדת מתחת ל־20, המערכת מפסיקה את מסלול המשלוחים ומעבירה את הרחפן למצב חזרה.

כאן נכיר פקודה חדשה:

`break` מסיימת מיד את הלולאה, גם אם נשארו חזרות נוספות.

המשתנים:

- `battery` רמת הסוללה.
- `distance_score` מדד התקדמות במסלול.
- `completed` מספר המקטעים שהושלמו.

### משימה א: קריאת קוד

```python
battery = int(input("Enter starting battery: "))

distance_score = 0
completed = 0
status = "Completed"

for section in range(1, 9):

    cost = 5 + section % 3
    battery -= cost

    if battery < 20:
        status = "Return"
        break

    completed += 1
    distance_score += section * 2

    if battery >= 50:
        distance_score += battery % 5

    elif battery >= 30:
        distance_score += 2

    else:
        distance_score += 1

print("Battery:", battery)
print("Distance score:", distance_score)
print("Completed:", completed)
print("Status:", status)
```

| 45 | ? | ? | ? | ? |
| 80 | ? | ? | ? | ? |

### שאלות חשיבה

1. האם הלולאה תמיד מתבצעת שמונה פעמים?
2. מה ההבדל בין `break` לבין סיום רגיל של לולאת `for`?
3. מדוע `completed += 1` מופיע אחרי בדיקת מצב הסוללה?
4. מה יקרה אם נמחק את פקודת `break`?

### משימה ב: כתיבת קוד עצמאית

פתחו מערכת לניהול **רובוט ניקיון אוטונומי**.

הרובוט יתחיל עם רמת סוללה שהמשתמש מכניס.

השתמשו בלולאת `for` שמדמה עד עשרה חדרים שהרובוט אמור לנקות.

בכל חדר הרובוט צורך אנרגיה לפי מספר החדר.

אם הסוללה יורדת מתחת ל־15, הרובוט מפסיק לנקות באמצעות `break`.

הגדירו גם מדד ניקיון ומונה חדרים שהושלמו.

בסיום הדפיסו את מצב הסוללה, מספר החדרים שנוקו ומצב המשימה.
