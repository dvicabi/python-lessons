# תרגיל 1: המזגן החכם בכיתה ❄️

## הסיפור

בית הספר החליט להתקין מזגנים חכמים שיודעים להגיב לטמפרטורה בכיתה.

בכל כיתה מותקן חיישן שמודד את הטמפרטורה ושולח אותה לתוכנית Python.

המערכת מחלקת את הטמפרטורה לשלושה מצבים:

- **Hot:** כאשר הטמפרטורה היא 30 מעלות ומעלה.
- **Warm:** כאשר הטמפרטורה היא 23 מעלות ומעלה, אבל נמוכה מ־30.
- **Cool:** בכל מצב אחר.

המערכת מנהלת שני משתנים:

`fan_score` מדד פעילות המאווררים.

`energy_score` מדד צריכת האנרגיה.

### משימה א: ניתוח הקוד

```python
temperature = int(input("Enter classroom temperature: "))

fan_score = 12
energy_score = 18

fan_score += temperature % 4
energy_score += fan_score // 5

if temperature >= 30:
    mode = "Hot"

    fan_score += 10
    energy_score += (temperature // 6) * 2
    fan_score += energy_score % 7
    energy_score -= fan_score // 8
    fan_score += (fan_score % 6) * 2
    energy_score += 3
    fan_score -= energy_score // 10

elif temperature >= 23:
    mode = "Warm"

    fan_score += 6
    energy_score += temperature % 5
    fan_score += energy_score // 6
    energy_score -= (fan_score % 4) * 2
    fan_score += 3
    energy_score += fan_score // 7
    fan_score -= energy_score % 3

else:
    mode = "Cool"

    fan_score += 2
    energy_score -= temperature % 4
    fan_score += energy_score // 8
    energy_score += fan_score % 5
    fan_score -= energy_score // 9
    energy_score += 2
    fan_score += energy_score % 3

fan_score += energy_score // 6
energy_score += fan_score % 5
fan_score -= energy_score // 12
energy_score += (fan_score % 4) * 2
fan_score += 3
energy_score -= fan_score // 10
fan_score += energy_score % 6
energy_score += 1

print("Mode:", mode)
print("Fan score:", fan_score)
print("Energy score:", energy_score)
```

השלימו את הטבלה:

| קלט | Mode | fan_score | energy_score |
|---|---|---|---|
| 20 | ? | ? | ? |
| 23 | ? | ? | ? |
| 32 | ? | ? | ? |

**שאלות:** איזה תנאי מתקיים כאשר הטמפרטורה היא בדיוק 23? מדוע החישובים שמופיעים אחרי ה־`else` מתבצעים בכל שלושת המקרים?

### משימה ב: פיתוח תנור חכם

כתבו תוכנית חדשה לניהול תנור אפייה חכם.

התוכנית תקלוט את טמפרטורת התנור ותנהל שני משתנים: `heat_score` ו־`cook_score`.

צרו שלושה מצבים לפי הטמפרטורה:

- 220 ומעלה: `High`
- 170 עד 219: `Medium`
- מתחת ל־170: `Low`

בתוך כל תנאי כתבו לפחות 5 פעולות מתמטיות שמשנות את המשתנים. לאחר התנאים כתבו עוד 8 פעולות שמתבצעות בכל מצב.

בסוף הדפיסו את מצב התנור ואת שני המדדים. בדקו את התוכנית עבור 150, 180 ו־230 מעלות.

# תרגיל 2: מערכת השקיה חכמה 🌱

## הסיפור

חקלאי מפעיל חממה עם מאות צמחים. השקיה ידנית של כל הצמחים דורשת זמן רב ועלולה לגרום לבזבוז מים.

כדי לפתור את הבעיה מותקן בחממה חיישן שמודד את רמת הלחות באדמה, בין 0 ל־100.

המערכת מקבלת את הנתון ומחליטה באיזה מצב השקיה לפעול:

- **Dry:** לחות של 25 ומטה.
- **Balanced:** לחות מעל 25 ועד 60.
- **Wet:** לחות מעל 60.

המערכת משתמשת בשני משתנים:

`water_score` מדד כמות ההשקיה.

`pump_score` מדד פעילות משאבת המים.

### משימה א: ניתוח הקוד

```python
moisture = int(input("Enter soil moisture: "))

water_score = 22
pump_score = 11

water_score += moisture % 6
pump_score += water_score // 7

if moisture <= 25:
    mode = "Dry"

    water_score += 12
    pump_score += (25 - moisture) // 5
    water_score += (pump_score % 5) * 3
    pump_score += water_score // 9
    water_score -= pump_score % 4
    pump_score += 4
    water_score += pump_score // 6

elif moisture <= 60:
    mode = "Balanced"

    water_score += 6
    pump_score += moisture % 7
    water_score += pump_score // 5
    pump_score -= water_score % 4
    water_score += (moisture // 10) * 2
    pump_score += water_score % 6
    water_score -= pump_score // 8

else:
    mode = "Wet"

    water_score -= 4
    pump_score += moisture % 8
    water_score += pump_score // 6
    pump_score -= (water_score % 5) + 1
    water_score += 2
    pump_score += water_score // 10
    water_score -= pump_score % 3

water_score += pump_score // 6
pump_score += water_score % 7
water_score -= pump_score // 9
pump_score += (water_score % 4) * 2
water_score += 3
pump_score -= water_score // 11
water_score += pump_score % 5
pump_score += 1

print("Mode:", mode)
print("Water score:", water_score)
print("Pump score:", pump_score)
```

| קלט | Mode | water_score | pump_score |
|---|---|---|---|
| 15 | ? | ? | ? |
| 40 | ? | ? | ? |
| 80 | ? | ? | ? |

**שאלות:** מדוע משתמשים ב־`<=` בתוכנית? מה יקרה אם נקבל לחות של בדיוק 25? האם המערכת תיכנס למצב `Dry` או `Balanced`?

### משימה ב: פיתוח מיכל מים חכם

כתבו תוכנית למיכל מים המחובר לחיישן שמודד את אחוז המילוי.

המערכת תקלוט את אחוז המים ותנהל שני משתנים: `pump_score` ו־`storage_score`.

התנאים:

- 20 אחוז ומטה: `Low`

עליכם להשתמש לפחות פעם אחת בכל אחת מהפעולות `+=`, `-=`, `//`, `%` ו־`*`.

# תרגיל 3: הרמזור החכם 🚦

## הסיפור

בצומת עמוס בעיר מותקן חיישן שסופר את מספר המכוניות שממתינות ברמזור.

רמזור רגיל משתמש בזמני המתנה קבועים. רמזור חכם יכול להשתמש בכמות המכוניות כדי להחליט כיצד לשנות את פעילותו.

התוכנית מקבלת מספר מכוניות ומחלקת את מצב הצומת לשלושה מצבים:

- **Heavy:** 40 מכוניות ומעלה.
- **Medium:** בין 15 ל־39 מכוניות.
- **Light:** פחות מ־15 מכוניות.

המשתנים שלנו:

`green_score` מדד זמן האור הירוק.

`traffic_score` מדד עומס התנועה.

### משימה א: ניתוח הקוד

```python
cars = int(input("Enter number of cars: "))

green_score = 20
traffic_score = 14

green_score += cars % 8
traffic_score += green_score // 6

if cars >= 40:
    mode = "Heavy"

    green_score += 15
    traffic_score += (cars // 10) * 3
    green_score += traffic_score % 7
    traffic_score -= green_score // 9
    green_score += (green_score % 5) * 2
    traffic_score += 4
    green_score -= traffic_score // 8

elif cars >= 15:
    mode = "Medium"

    green_score += 8
    traffic_score += cars % 6
    green_score += traffic_score // 5
    traffic_score -= green_score % 4
    green_score += (cars // 8) * 2
    traffic_score += green_score // 10
    green_score -= traffic_score % 3

else:
    mode = "Light"

    green_score += 3
    traffic_score += cars % 5
    green_score += traffic_score // 7
    traffic_score -= green_score // 10
    green_score += traffic_score % 4
    traffic_score += 2
    green_score -= traffic_score % 3

green_score += traffic_score // 6
traffic_score += green_score % 5
green_score -= traffic_score // 11
traffic_score += (green_score % 4) * 2
green_score += 3
traffic_score -= green_score // 12
green_score += traffic_score % 6
traffic_score += 1

print("Mode:", mode)
print("Green score:", green_score)
print("Traffic score:", traffic_score)
```

# תרגיל 4: עמדת טעינה חכמה 🔋

## הסיפור

חברה המפתחת עמדות טעינה לאופניים חשמליים רוצה ליצור מערכת שמתאימה את מצב הטעינה לאחוז הסוללה.

המערכת מקבלת מהמשתמש את אחוז הסוללה ומבצעת חישובים על שני מדדים.

מצבי המערכת:

- **Low:** הסוללה מכילה 20 אחוז ומטה.
- **Medium:** הסוללה מכילה מעל 20 ועד 70 אחוז.

המשתנים הם:

`charge_score` מדד פעילות הטעינה.

`power_score` מדד האנרגיה של המערכת.

### משימה א: ניתוח הקוד

```python
battery = int(input("Enter battery percentage: "))

charge_score = 20

if battery <= 20:

    power_score += battery % 7
    charge_score += power_score // 6
    power_score -= charge_score % 5
    charge_score += (battery // 20) * 2
    power_score += charge_score % 4
    charge_score -= power_score // 9

else:
    mode = "High"

    charge_score += 2
    power_score -= battery % 5
    charge_score += power_score // 7
    power_score += charge_score % 3
    charge_score -= power_score // 8
    power_score += 3
    charge_score += power_score % 4
```

# תרגיל 5: מד הרעש החכם בכיתה 🔊

## הסיפור

לפעמים כיתה יכולה להיות כל כך רועשת שקשה לשמוע את המורה.

כדי לעזור בניהול סביבת הלמידה, בית הספר מתקין חיישן רעש שמודד את עוצמת הקול בכיתה.

החיישן שולח מספר לתוכנית. התוכנית קובעת את מצב הרעש לפי הכללים:

- **Medium:** עוצמת רעש 55 עד 79.
- **Quiet:** עוצמת רעש מתחת ל־55.

המערכת משתמשת בשני משתנים:

`alert_score` מדד הצורך בהתראה.

`focus_score` מדד תנאי הריכוז בכיתה.

### משימה א: ניתוח הקוד

```python
noise = int(input("Enter classroom noise level: "))

alert_score = 8

alert_score += noise % 5
focus_score -= alert_score // 4

if noise >= 80:
    mode = "Noisy"

    alert_score += 15
    focus_score -= noise // 20
    alert_score += (focus_score % 6) * 2
    focus_score -= alert_score // 8
    alert_score += 3
    focus_score += alert_score % 4
    alert_score -= focus_score // 12

elif noise >= 55:
    mode = "Medium"

    alert_score += 8
    focus_score -= noise % 7
    alert_score += focus_score // 7
    focus_score += alert_score % 5
    alert_score += (noise // 20) * 2
    focus_score -= alert_score // 9
    alert_score -= focus_score % 3

else:
    mode = "Quiet"

    alert_score += 2
    focus_score += noise % 6
    alert_score += focus_score // 8
    focus_score -= alert_score % 4
    alert_score += noise // 15
    focus_score += alert_score % 3
    alert_score -= focus_score // 10

alert_score += focus_score // 6
focus_score += alert_score % 5
alert_score -= focus_score // 11
focus_score += (alert_score % 4) * 2
alert_score += 3
focus_score -= alert_score // 10
alert_score += focus_score % 6
focus_score += 1

print("Mode:", mode)
print("Alert score:", alert_score)
print("Focus score:", focus_score)
```
