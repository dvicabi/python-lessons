## חלק א: איך המקרר יודע מתי להפעיל קירור?

דמיינו שאתם עובדים בחברה שמפתחת מקררים חכמים.

בכל מקרר מותקן חיישן טמפרטורה שמודד כמה מעלות יש בתוך המקרר.

אבל החיישן עצמו לא יודע לקבל החלטות. הוא רק שולח מספר.

**התפקיד שלנו כמתכנתים הוא להפוך את המספר הזה להחלטה.**

לדוגמה:

- אם הטמפרטורה היא 10 מעלות ומעלה, המקרר נכנס למצב חירום ומגביר את הקירור.
- אחרת, אם הטמפרטורה היא 6 מעלות ומעלה, המקרר נכנס למצב אזהרה.
- אחרת, המקרר ממשיך לפעול במצב רגיל.

אלו כללים שקבענו לצורך התרגיל.

בתוכנית שלנו יש שני מדדים:

`heat_score` מייצג מדד עומס חום.

`cooling_score` מייצג מדד פעילות של מערכת הקירור.

המדדים הם ערכים שהמצאנו כדי לתרגל חישובים. הם לא טמפרטורות או מדידות פיזיקליות אמיתיות.

## הקוד שקיבלתם

```python
temperature = int(input("Enter the fridge temperature: "))

heat_score = 20
cooling_score = 8

heat_score += temperature % 5
cooling_score += heat_score // 6

if temperature >= 10:
    mode = "Emergency"

    cooling_score += 12
    heat_score += (temperature // 2) * 3
    cooling_score += heat_score % 6
    heat_score -= cooling_score // 5
    cooling_score += (heat_score // 7) * 2
    heat_score += 4
    cooling_score -= heat_score % 4
    heat_score -= cooling_score // 8

elif temperature >= 6:
    mode = "Warning"

    cooling_score += 6
    heat_score += (temperature % 4) * 3
    cooling_score += heat_score // 5
    heat_score -= (cooling_score % 5) * 2
    cooling_score -= heat_score // 8
    heat_score += 3
    cooling_score += heat_score % 6
    heat_score -= cooling_score // 7

else:
    mode = "Normal"

    cooling_score += 2
    heat_score -= temperature % 3
    cooling_score += heat_score // 10
    heat_score += cooling_score % 4
    cooling_score -= heat_score // 8
    heat_score += 2
    cooling_score += heat_score % 5
    heat_score -= cooling_score // 6

heat_score += cooling_score // 5
cooling_score += heat_score % 7
heat_score -= (cooling_score % 3) + 1
cooling_score += heat_score // 9
heat_score += 2
cooling_score -= heat_score % 4
heat_score += (cooling_score // 6) * 2
cooling_score += heat_score % 5
heat_score -= cooling_score // 11
cooling_score += 1

print("Mode:", mode)
print("Heat score:", heat_score)
print("Cooling score:", cooling_score)
```

## חלק ב: עכשיו אתם המתכנתים! 🌱

### משימה 2: פיתוח חממה חכמה

בחממה חקלאית מגדלים צמחים שצריכים טמפרטורה מתאימה כדי לגדול.

כאשר חם מדי, צריך להגביר את האוורור ולבחון את צורכי ההשקיה.

כאשר קר מדי, צריך להקטין את האוורור.

התפקיד שלכם הוא לכתוב תוכנית חדשה שעוזרת למערכת החממה להחליט כיצד לפעול.

### דרישות התוכנית

**1. קבלת נתונים**

בקשו מהמשתמש להכניס את הטמפרטורה בחממה באמצעות `input`, והמירו אותה למספר שלם.

**2. הגדרת משתנים**

צרו שני משתנים עם ערכים התחלתיים שאתם בוחרים:

- `fan_score` מדד פעילות המאווררים.
- `water_score` מדד השקיה.

**3. כתיבת תנאים**

כתבו שלושה מסלולים:

- `if`: אם הטמפרטורה היא 30 מעלות ומעלה, מצב חם.
- `elif`: אחרת, אם הטמפרטורה היא 20 מעלות ומעלה, מצב רגיל.
- `else`: בכל מצב אחר, מצב קר.

**4. פעולות חשבוניות**

בתוך כל אחד משלושת המסלולים כתבו לפחות **4 פעולות מתמטיות** שמשנות את ערכי המשתנים.

עליכם להשתמש בפעולות הבאות לאורך התוכנית:

`+=` , `-=` , `*` , `//` , `%`

מותר לכם לשלב כמה פעולות באותו חישוב, למשל:

```python
fan_score += water_score % 4
```

**5. המשך חישובים**

אחרי כל שלושת התנאים, כתבו לפחות **5 פעולות מתמטיות נוספות** שיתבצעו בכל מצב, בלי קשר לטמפרטורה שהתקבלה.

**6. הדפסת תוצאות**

בסוף התוכנית הציגו את מצב החממה ואת הערכים הסופיים של שני המדדים.

### בדיקת התוכנית שלכם
