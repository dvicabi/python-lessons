# משימה: המקרר החכם 🧊

### למה אנחנו בכלל צריכים פעולות חשבוניות בתכנות?

דמיינו שאתם מהנדסי תוכנה בחברה שמפתחת מקררים חכמים.

במקרר מותקן חיישן שמודד את הטמפרטורה בכל כמה שניות. יום אחד, מישהו שוכח לסגור את דלת המקרר.

הטמפרטורה מתחילה לעלות, אבל איך המקרר יודע שמשהו לא תקין? איך הוא יודע מתי צריך להגביר את הקירור או להפעיל התראה?

**כאן נכנס התפקיד שלנו כמתכנתים.**

החיישן מספק נתונים. התוכנה שלנו צריכה לקבל אותם, לבצע חישובים, לעבד את התוצאות ולהחליט מה לעשות.

לצורך התרגיל נבנה הדמיה פשוטה של מערכת הבקרה.

יש לנו שני משתנים:

- `num1` מייצג מדד חום המחושב מנתוני החיישן.
- `num2` מייצג מדד פעילות של מערכת הקירור.

אלה מדדים מספריים שהמצאנו לצורך התרגול, ולא טמפרטורות אמיתיות או נוסחאות פיזיקליות של מקרר.

בכל שורת קוד המערכת מעדכנת את אחד המדדים. החישוב הבא מתבסס על הערכים שכבר עודכנו.

### המשימה שלכם

עליכם לעקוב אחרי הקוד מתחילתו ועד סופו, ולגלות מה יהיו הערכים הסופיים של שני המשתנים.

**שימו לב:** אסור לחשב כל שורה בנפרד לפי הערכים הראשוניים. כל שינוי נשמר ומשפיע על החישובים הבאים!

```python
1. num1 = 24
2. num2 = 6

3. num1 += 3
4. num2 += num1 % 5
5. num1 -= num2 // 4
6. num2 += (num1 // 5) * 2

7. num1 += (num2 % 7) * (num1 // 5)
8. num2 -= 5
9. num1 -= (num1 // 9) * (num2 % 4)
10.num2 += num1 // 8

11.num1 += num2 // 6 + 2
12.num2 -= (num1 % 8) + 1
13.num1 -= num2 % 5
14.num2 += (num1 // 10) * (num2 % 5)

15.num1 += 5
16.num2 -= num1 // 12
17.num1 -= (num2 // 4) * (num1 % 7)
18.num2 += num1 % 9

19.num1 += num2 // 11
20.num2 -= (num1 // 13) + num2 % 6
21.num1 += (num1 % 5) * (num2 // 8)
22.num2 += 3

23.num1 -= num2 // 6
24.num2 += num1 % 4
25.num1 += (num2 // 5) * (num1 % 6)
26.num2 -= num1 % 7

27.num1 += num2 // 19 + 1
28.num2 += num1 % 6
29.num1 -= num2 // 5
30.num2 -= num1 // 9

31.num1 += (num1 % num2) * (num2 // 8)
32.num2 -= num1 // 10

33.print("Heat:", num1)
34.print("Cooling:", num2)
```

### איך פותרים?

מומלץ להכין טבלת מעקב במחברת עם שלוש עמודות:

דוגמה לטבלה **num1 | num2**

אחרי כל פעולה מעדכנים את המשתנה שהשתנה, ואת המשתנה השני משאירים כפי שהיה.

זכרו את הפעולות שלמדנו:

`+=` הוספה לערך הקיים

`-=` הפחתה מהערך הקיים

`//` חלוקה שלמה, עם עיגול כלפי מטה

`%` שארית החלוקה

`*` כפל
