בכל בדיקה הטמפרטורה עשויה להשתנות, והמערכת מעדכנת את פעילות המאווררים.

במקום להפעיל את החישובים באופן ידני, נגדיר מחלקה עם מתודה בשם `measure` ונפעיל אותה באמצעות לולאת `for`.

### משימה א: קריאת קוד

```python
class Greenhouse:

    def __init__(self, temperature):
        self.temperature = temperature
        self.fan_score = 5
        self.alerts = 0

    def measure(self, hour):
        self.temperature += hour % 3

        if self.temperature >= 30:
            self.fan_score += self.temperature // 10
            self.alerts += 1

        elif self.temperature >= 23:
            self.fan_score += 2

        else:
            self.fan_score += 1

        self.temperature -= self.fan_score % 3


temperature = int(input("Enter temperature: "))

house = Greenhouse(temperature)

for hour in range(1, 5):
    house.measure(hour)

print("Temperature:", house.temperature)
print("Fan score:", house.fan_score)
print("Alerts:", house.alerts)
```

```python
class WaterTank:

    def __init__(self, level):
        self.level = level
        self.cycles = 0
        self.pump_score = 3

    def fill_once(self):
        self.cycles += 1
        self.level += 3 + self.cycles % 2

        if self.level >= 20:
            self.pump_score += self.level % 4 + 2

        else:
            self.pump_score += self.cycles % 3

        self.pump_score -= self.cycles // 3


level = int(input("Enter water level: "))

tank = WaterTank(level)

while tank.level < 20 and tank.cycles < 5:
    tank.fill_once()

if tank.level >= 20:
    status = "Full"
else:
    status = "Stopped"

print("Level:", tank.level)
print("Cycles:", tank.cycles)
print("Pump score:", tank.pump_score)
print("Status:", status)
```

# תרגיל 8: רובוט המשלוחים החכם 🤖

## הסיפור

חברת משלוחים מפעילה רובוט אוטונומי שמעביר חבילות בין עמדות במחסן.

אבל לרובוט יש גם סוללה.

לפני כל תנועה הוא בודק אם נשארה לו מספיק אנרגיה כדי להמשיך.

נגדיר מחלקה עם שתי מתודות:

`move_toward` מקדמת את הרובוט לכיוון היעד.

`can_continue` מחזירה `True` כאשר רמת הסוללה מאפשרת להמשיך, או `False` כאשר צריך לעצור.

### משימה א: קריאת קוד

```python
class DeliveryRobot:

    def __init__(self, position):
        self.position = position
        self.battery = 30
        self.steps = 0

    def move_toward(self, target):
        if self.position < target:
            self.position += 1

        elif self.position > target:
            self.position -= 1

        self.steps += 1
        self.battery -= 2 + self.position % 3

        return self.position

    def can_continue(self):
        return self.battery >= 10


target = int(input("Enter target position: "))

robot = DeliveryRobot(3)

while robot.position != target and robot.can_continue() and robot.steps < 8:
    robot.move_toward(target)

if robot.position == target:
    status = "Arrived"
else:
    status = "Stopped"

print("Position:", robot.position)
print("Battery:", robot.battery)
print("Steps:", robot.steps)
print("Status:", status)
```

### משימה א: קריאת קוד

```python
class TemperatureSensor:

    def __init__(self, reading):
        self.reading = reading

    def read_next(self, minute):
        self.reading += minute % 4 - 1

        return self.reading


class FridgeController:

    def __init__(self):
        self.cooling = 4
        self.warnings = 0

    def update(self, temperature):
        if temperature >= 10:
            self.cooling += temperature // 2
            self.warnings += 1

        elif temperature >= 6:
            self.cooling += temperature % 3 + 2

        else:
            self.cooling += 1

        self.cooling -= self.warnings % 2


reading = int(input("Enter first reading: "))

sensor = TemperatureSensor(reading)
controller = FridgeController()

for minute in range(1, 5):
    temperature = sensor.read_next(minute)
    controller.update(temperature)

print("Reading:", sensor.reading)
print("Cooling:", controller.cooling)
print("Warnings:", controller.warnings)
```

# תרגיל 10: רובוט אבטחה עם ירושה 🚨

## הסיפור

חברה מייצרת כמה סוגים של רובוטים.

יש רובוטים שמנקים, רובוטים שמובילים חבילות ורובוטים שמסיירים לצורכי אבטחה.

לכל הרובוטים יש תכונות משותפות, למשל רמת אנרגיה ומספר תנועות.

האם אנחנו צריכים לכתוב מחדש את אותן תכונות ומתודות עבור כל סוג של רובוט?

לא בהכרח.

אפשר ליצור מחלקה כללית בשם `Robot`, ואז ליצור מחלקה חדשה בשם `SecurityRobot` שמבוססת עליה.

למנגנון הזה קוראים **ירושה (Inheritance)**.

ב־Python כותבים את שם מחלקת הבסיס בסוגריים:

```python
class SecurityRobot(Robot):
```

כך המחלקה החדשה יכולה להשתמש במתודות ובתכונות של המחלקה שממנה היא יורשת.

הפקודה `super().__init__(energy)` מפעילה את הבנאי של מחלקת הבסיס, כדי לאתחל את התכונות המשותפות.

### משימה א: קריאת קוד

```python
class Robot:

    def __init__(self, energy):
        self.energy = energy
        self.steps = 0

    def move(self, cost):
        self.energy -= cost
        self.steps += 1


class SecurityRobot(Robot):

    def __init__(self, energy):
        super().__init__(energy)
        self.alerts = 0

    def scan(self, reading):
        if reading >= 60:
            self.alerts += 1
            self.move(5)

        elif reading >= 30:
            self.move(3)

        else:
            self.move(2)

        self.energy += reading % 3


reading = int(input("Enter first reading: "))

robot = SecurityRobot(24)

for round_number in range(1, 5):
    reading += round_number * 3
    robot.scan(reading)

    if robot.energy < 10:
        break

print("Reading:", reading)
print("Energy:", robot.energy)
print("Steps:", robot.steps)
print("Alerts:", robot.alerts)
```
