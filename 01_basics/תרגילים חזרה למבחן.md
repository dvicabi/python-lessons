### שאלה 11: מעקב אחר משתנים ואופרטורים, 20 נקודות

לפניכם קטע קוד בשפת Python:

```
a = 26
b = 7

print(a + b)

a += b
b *= 2

print(a, b)
print(a // b)
print(a % b)
```

**משימות:**

1. עקבו אחר ערכי המשתנים לאורך התוכנית.
2. כתבו את כל הפלט לפי סדר ההדפסה.
3. הסבירו כיצד התקבלה התוצאה של פעולת `%` בשורה האחרונה.

### שאלה 12: קריאת קוד, חישוב מחיר לאחר הנחה, 20 נקודות

```
price = "140"
discount = 20
quantity = 3

unit_price = int(price)
subtotal = unit_price * quantity
final_price = subtotal - discount

print(f"Subtotal: {subtotal}")

print(type(final_price))
```

**משימות:**

1. כתבו את הפלט המלא של התוכנית, בדיוק כפי שיופיע על המסך.
2. הסבירו מדוע השתמשנו ב-`int(price)`.
3. מהו סוג הנתונים של המשתנה `final_price`?
