| 61–80 | רקורסיה, סדר קריאות, עצי חזרה, פונקציות פנימיות | [04_recursion_advanced](./04_recursion_advanced/) |

## איך מתרגלים?
1. פותחים `exercise_XX.py` ומנסים לחשב את **כל שורות הפלט** ללא הרצה.
2. בונים טבלת מעקב לכל קריאה; בפונקציה רקורסיבית מסמנים גם כניסה, תנאי עצירה, חזרה.
3. בודקים את שורות ההדפסה מול הקטע המסומן `# >>> EXPECTED OUTPUT` בתחתית הקובץ.
4. אפשר לראות את [80 הפתרונות במקום אחד](./ANSWERS.md).
5. בדיקה אוטומטית מופעלת ב־GitHub Actions לכל מאגר התרגילים, כולל 80 החדשים.

התרגילים מסודרים מהיסודות אל תרגילים מתקדמים.
בתוך קוד התרגילים **אין פקודות `break` או `continue`**.
