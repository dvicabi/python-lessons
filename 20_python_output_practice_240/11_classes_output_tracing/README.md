# מחלקות ואובייקטים | 40 תרגילי חיזוי פלט ב־Python

40 תרגילים מדורגים המתרגלים OOP באמצעות חיזוי פלט וטבלת מעקב. לכל תרגיל **קובץ Python עצמאי**, ובתחתיתו התשובה הסופית כהערות (כך שהפתרון לא יודפס בזמן ריצה).

| תרגילים | נושאים | קישור |
|---|---|---|
| 01–10 | יצירת מחלקה, אובייקטים, מאפיינים, הפניות ושינוי ערכים | [מחלקות ואובייקטים](./01_classes_objects/) |
| 11–20 | `__init__`, `self`, מתודות, `return`, ברירת מחדל, שינוי מצב | [בנאים ומתודות](./02_init_methods/) |
| 21–30 | מאפייני מחלקה מול מאפייני מופע, `@classmethod`, `@staticmethod`, `@property`, `__str__`, `__len__` | [מאפייני מחלקה ומתודות מיוחדות](./03_class_attributes_special_methods/) |
| 31–40 | ירושה, `super()`, דריסת מתודות, פולימורפיזם, `isinstance`, הרכבה (Composition) | [ירושה ופולימורפיזם](./04_inheritance_polymorphism/) |

## איך מתרגלים
1. פותחים את `exercise_XX.py` בתיקייה המתאימה.
2. עוקבים אחר יצירת האובייקטים וסדר הקריאות למתודות. כותבים מראש מה יודפס.
3. מומלץ להכין טבלת מעקב: שורה לכל פעולה, עמודות לכל אובייקט ולמאפייניו; בנוסף עקבו אחרי ערכי מחלקה משותפים.
4. רק לאחר הפתרון, משווים לפלט שמופיע בתחתית קובץ התרגיל בין `# >>> EXPECTED OUTPUT` ל־`# <<< END EXPECTED OUTPUT`.
5. כל התשובות מרוכזות בקובץ [ANSWERS.md](./ANSWERS.md).

## דגשים חשובים
- שימו לב להבדל בין מאפיין מחלקה למאפיין מופע ולשיתוף רשימה המוגדרת ברמת המחלקה.
- `print` מתבצע בזמן הקריאה; `return` מחזיר ערך ואינו מדפיס אוטומטית.
- בירושה, בדקו אם מתודה נדרסת, מה מבצע `super()`, ומהו סוג האובייקט בזמן הריצה.
- קוד התרגילים לא דורש חבילות חיצוניות. לא נעשה שימוש בפקודות `break` או `continue`.
