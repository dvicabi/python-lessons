## איך עובדים
1. פותחים את `exercise_01.py` בתיקייה הרצויה.
2. קוראים את הקוד וכותבים על דף את הפלט המדויק **בלי להריץ**.
3. בתרגילי תנאים, `while` ו־`for` מומלץ להכין טבלת מעקב (איטרציה והערכים של המשתנים).
4. מריצים ובודקים את הפתרון המופיע **בתחתית אותו קובץ** כהערות, אחרי הסימון `# >>> EXPECTED OUTPUT`.
5. ניתן לבדוק פתרונות גם בקובץ [פתרונות_סופיים.md](./פתרונות_סופיים.md), או בקובץ `ANSWERS.md` בכל נושא.

## סדר הנושאים
הדפסה (`print`, `sep`, `end`) → משתנים ומחרוזות → חשבון (`//`, `%`, `**`) → תנאים (`if`, `elif`, `else`, `and`, `or`) → `while` → `for` → רשימות → פונקציות → רקורסיה → מחלקות ואובייקטים.

## סדר התרגול
התרגילים בכל נושא מחולקים לארבע סדרות של עשרה תרגילים. בסדרות המאוחרות משתנים גם הערכים ונדרש לעיתים יותר מעקב. אפשר להתחיל מכל סדרה מתאימה.
