# 40 תרגילי לולאות מקוננות | ללא break / continue

## מה יש כאן?
40 קובצי Python עצמאיים, `exercise_01.py` עד `exercise_40.py`. בכל קובץ תרגיל חיזוי פלט, ובתחתיתו הפלט הסופי כהערות.

**דרגת קושי:** 01–10 מתקדם, 11–20 קשה, 21–30 קשה מאוד, 31–40 אתגר קצה.

התרגילים משלבים 2–3 לולאות מקוננות: `for` בתוך `for`, `while` בתוך `while`, ושילובים של `for` ו-`while`, עם תנאים ומספר משתנים שמשפיעים זה על זה.

**אין בקוד התרגילים פקודות `break` או `continue`.** כל לולאה מסתיימת באופן רגיל.

## איך לתרגל
1. פותחים קובץ לפי מספרו.
2. מחשבים ידנית מה יודפס, כולל סדר השורות והרווחים.
3. בונים טבלת מעקב עם עמודות למשתני כל הלולאות ולמשתנים שמשתנים.
4. משווים לפתרון בתחתית הקובץ, בין הסמנים `EXPECTED OUTPUT`.
5. אפשר לראות גם את [כל הפלטים הסופיים](./ANSWERS.md).

## בדיקת תקינות
הקובץ [verify_exercises.py](../verify_exercises.py) מריץ את כל התרגילים ובודק שהפלט שלהם מתאים לתשובות שבתחתית הקבצים.

### בונוס למורה
לתרגול מדורג: התחילו במספרים 01–10, אחר כך 11–20, ולבסוף 21–40. התרגילים המאוחרים כוללים חישובים שתלויים בנתוני הסיבוב הקודם, לכן חשוב לעקוב אחרי סדר ביצוע.
