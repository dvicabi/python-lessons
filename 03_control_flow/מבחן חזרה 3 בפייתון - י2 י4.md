## חלק ב: קריאת קוד (40 נקודות)

### שאלה 7: לולאות וסכום ספרות (20 נקודות)

לפניכם קטע קוד:

```python
number = 9536
total = 0

while number > 0:
    digit = number % 10
    if digit >= 5:
        total += digit
    number //= 10

print(total, number)
```

**א. (5 נקודות)** כתבו את הפלט המדויק של התוכנית.

**ב. (12 נקודות)** השלימו את טבלת המעקב. בכל שורה רשמו את הערכים בסיום האיטרציה המתאימה.

| איטרציה | number בתחילה | digit | האם התנאי מתקיים? | total בסיום | number בסיום |
| --- | --- | --- | --- | --- | --- |
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |

**ג. (3 נקודות)** הסבירו במילים שלכם מה התוכנית מחשבת.

### שאלה 8: קריאת קוד ונתוני תלמיד (20 נקודות)

תלמיד מזין, לפי הסדר, את הערכים הבאים:

`Tamar`  
`5`  
`Robotics`

לפניכם התוכנית:

```python
student = input("Student: ")

course = input("Course: ")

print(can_join)
print(course[2])
```

**א. (6 נקודות)** כתבו את שלוש שורות הפלט שמפיקות פקודות ה-`print`, לפי הסדר.

**ב. (6 נקודות)** מהו סוג הנתון של כל אחד מהמשתנים `student`, `completed` ו-`can_join`?

**ג. (5 נקודות)** הסבירו במילים מה בודק הביטוי `completed >= 5 and "R" in course`.

**ד. (3 נקודות)** מה משמעות הביטוי `course[2]`?

### שאלה 9: מערכת למעקב תרגול שבועי

בית ספר רוצה ליצור תוכנית שעוזרת לתלמידים לעקוב אחר ההתקדמות שלהם בתרגול.

כתבו תוכנית מלאה בפייתון שמבצעת את הפעולות הבאות:

1. קולטת את שם התלמיד כמחרוזת.
2. קולטת את שם המקצוע כמחרוזת.
3. קולטת את מספר התרגילים שהתלמיד פתר כמספר שלם.
4. קולטת את יעד התרגילים השבועי כמספר שלם.
5. מחשבת כמה תרגילים נותרו עד היעד באמצעות חיסור: יעד פחות מספר התרגילים שנפתרו.
6. שומרת במשתנה בוליאני האם מספר התרגילים שנפתרו גדול מהיעד או שווה לו.
7. שומרת במשתנה בוליאני נוסף האם האות הקטנה `"i"` נמצאת בשם המקצוע.
8. יוצרת משתנה בוליאני שלישי שבודק באמצעות `and` האם שני התנאים הקודמים מתקיימים יחד.
9. מדפיסה את מספר התרגילים שנותרו ואת שלושת הערכים הבוליאניים.
10. מדפיסה שורת סיכום באמצעות `f-string` הכוללת את שם התלמיד, שם המקצוע, מספר התרגילים שנפתרו, היעד והערך הבוליאני השלישי.

**חלוקת הניקוד:** קליטה והמרות 10, חישוב ותנאים 15, הדפסות 10, קריאות ותקינות הקוד 5.
