### שאלה 7: לולאה וספירת ספרות (20 נקודות)

לפניכם התוכנית:

```python
number = 7836
count = 0

while number > 0:
    digit = number % 10
    if digit % 2 != 0:
        count += 1
    number //= 10

print(count, number)
```

**א. (5 נקודות)** מה יהיה הפלט המדויק של התוכנית?

**ב. (12 נקודות)** השלימו את טבלת המעקב:

| איטרציה | number בתחילה | digit | האם התנאי מתקיים? | count בסיום | number בסיום |
| --- | --- | --- | --- | --- | --- |
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |

**ג. (3 נקודות)** הסבירו במילים מה התוכנית סופרת.

### שאלה 8: קריאת קוד ומסלול לימודים (20 נקודות)

המשתמש מקליד לפי הסדר:

`Science`

לפניכם התוכנית:

```python
name = input("Name: ")

print(f"{name} - {track}")
print(is_approved)
print(len(track))
```

**א. (6 נקודות)** כתבו את שלוש שורות הפלט שמפיקות פקודות ה-`print`, לפי הסדר.

**ג. (5 נקודות)** הסבירו באילו מצבים הביטוי `completed >= 7 or "S" in track` מחזיר `True`.

**ד. (3 נקודות)** מה בודקת ההדפסה האחרונה בתוכנית?
