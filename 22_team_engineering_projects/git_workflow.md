# ניהול גרסאות לצוותים שלמדו Git

הפרויקט ניתן לביצוע גם ללא Git, באמצעות שיתוף קובצי Python אישיים וחיבור מסודר. אין צורך בחשבונות חיצוניים של תלמידים כדי לבצע את משימות הליבה.

אם משתמשים ב-Git, פתחו מאגר נפרד לצוות או עותק שהמורה מנהל. אין לתת הרשאות כתיבה למאגר הקורס הראשי.

## אחריות

כל תלמיד עורך רק את קובץ הרכיב שהוקצה לו בתיקיית starter. קובץ ההסכם משותף; עדכונו דורש אישור. לא מתחילים לערוך main.py משותף במקביל.

## עבודה על ענף

לאחר שהמורה הכין מאגר מקומי וכל תלמיד יודע להשתמש ב-Git:

```bash
git switch main
git pull
git switch -c student-01-flights
```

שנו את שם הענף ואת שם הקובץ לפי הפרויקט והתפקיד. לאחר כתיבה ובדיקה:

```bash
git add starter/01_flights.py
git commit -m "Implement flight lookup"
git push -u origin student-01-flights
```

פתחו בקשת מיזוג (Pull Request). חבר צוות שצורך את הפלט קורא את הקוד, מריץ את דוגמת הממשק ומאשר רק לאחר בדיקה.

אין למזג שינוי בחוזה הממשקים לפני אישור התלויים בו. אחראי האינטגרציה מתחלף ומרכז מיזוגים, אך אינו כותב את הקוד של חבריו.

## התקדמות למודולים

רק לאחר לימוד פעולות, ובהמשך import, אפשר להחליף מקטעי קוד בפעולות עם פרמטרים וערכים מוחזרים. אפשר לתת לכל תלמיד מודול נפרד ולהשתמש ב-main.py כמתאם. בשלב מחלקות מעצבים אובייקטים ותלויות ביניהם.

אין לדרוש Git, import, פעולות או מחלקות כתנאי לפתיחת הפרויקט ברמה מוקדמת.
