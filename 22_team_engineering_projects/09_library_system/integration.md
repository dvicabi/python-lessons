# חיבור הרכיבים

## מסלול ללא פעולות ומחלקות

1. שמרו עותק של `starter/scenario.py` בשם `main.py` במחשב הצוות. נתוני התרחיש נמצאים בתחילת הקובץ.

2. כל תלמיד כותב בקובץ האישי שלו את הקוד שאחראי לפלט שהוגדר בהסכם. בזמן בדיקה אישית אפשר להכין קלטי דמה מקומיים.

3. חברו ל-`main.py` רק את לוגיקת הרכיב, ללא קלטי הדמה האישיים. סדר החיבור: 1, 2, 3, 4, 5, 6. אין להזין ערך קבוע עבור פלט של רכיב קודם.

4. לאחר כל חיבור, שני בעלי הרכיבים הרלוונטיים מריצים בדיקה יחד. אם נדרש תיקון, כל בעל רכיב מתקן את הקוד שלו.

5. בסוף הקובץ הציגו את המדדים הבאים (בדיוק השמות שהוסכמו):

```python
print("result:", result)
print("copy_index:", copy_index)
print("due:", due)
print("holders_after:", holders_after)
print("reserved_after:", reserved_after)
print("limits_after:", limits_after)
print("used_after:", used_after)
```

6. הריצו את כל תרחישי הקבלה המשותפים מתוך [תרחישי הקבלה](test_scenarios.md). בכל תרחיש מתחילים מחדש מנתוני ההתחלה ומשנים רק את הערכים שנקבעו.

## הגבלות לפי חומר נלמד

ברמות ההתחלה מותר לעבוד על דוחות באמצעות print ו-end, אחר כך משתנים וחשבון, קלט, תנאים, לולאות ורשימות. בשלב רשימות מחברים את המוצר כולו. רק לאחר לימוד פעולות אפשר להפוך רכיב לפעולה עם פרמטרים וערך מוחזר (ערך יחיד או רשימה). לאחר לימוד מחלקות אפשר לתת לכל מערכת אובייקט עצמאי.

אין להשתמש במבני נתונים מלבד רשימות. סיום לולאה וסינון אירועים נעשים באמצעות תנאים ומונים.

אם הכיתה כבר למדה import, העבירו כל פעולה לקובץ נפרד וייבאו אותה ל-main.py. אין להשתמש ב-import לפני שהמורה לימד זאת.

## סבב שני: מצב שנשמר בין בקשות

בקשה חדשה של אותו קורא לספר זהה: העותק הקודם כבר הושאל ולכן נבחר עותק אחר.

הריצו תחילה את התרחיש המקורי. אין לאתחל שוב את נתוני ההתחלה. העבירו את המצב הסופי למשתני הקלט של ההרצה השנייה בהתאם למיפוי הבא:

```python
holders = holders_after
reserved = reserved_after
limits = limits_after
used_ids = used_after
loan_id = 52
```

**איך מבצעים את הסבב השני בלי פעולות?** בסוף main.py, אחרי הדוח הראשון, הוסיפו את השורות של העברת המצב שמופיעות למעלה. אחריהן העתיקו פעם נוספת את ששת מקטעי הלוגיקה לפי הסדר ואת פקודות הדוח, בלי להעתיק את נתוני ההתחלה. עכשיו הרצה אחת של main.py תציג שני דוחות. לאחר לימוד לולאות ניתן להעביר את ששת המקטעים ללולאה של שני סבבים, ולאחר לימוד פעולות אפשר להפעיל את אותה פעולה פעמיים.

התוצאה הנדרשת לאחר הסבב השני:

```text
result = "OK"
copy_index = 1
due = 17
holders_after = [0, 101, 101, 0]
limits_after = [0, 1]
used_after = [50, 51, 52]
```

בדקו שאין הקצאה כפולה או הפחתה נוספת כאשר הבקשה נדחית. כל בעל רכיב מסביר מה נקרא מחדש ומה נשמר בין ההרצות.
