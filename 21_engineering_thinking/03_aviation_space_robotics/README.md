# תחום 03: תעופה, חלל ורובוטיקה

שמונה מערכות חדשות, משימות 17–24 במאגר.

בכל מערכת שמונה רמות מצטברות וארבע משימות משנה בכל רמה.

הקוד ארוך ומורכב יותר מהתחום הקודם; מתחילים בתצוגה של 12 פקודות ומגיעים לקטעי קריאה עד 54 שורות, כולל מחלקות משתפות פעולה.

כל הרמות עומדות בפני עצמן. אין צורך ללמוד נושאים שטרם נלמדו.

## המשימות

- [17. מחשב בקרה במטוס](17_aircraft_computer.md) — אימות חיישנים, פערים, רצפים והפרדת אחריות.
- [18. ניהול דלק במטוס](18_aircraft_fuel_budget.md) — תכנון חלופות, תנאי סף וניקוד בתקציב בדוי.
- [19. רובוט מחקר במאדים](19_mars_rover.md) — מרווח חזרה, מניעת איסוף כפול ומצב.
- [20. לוויין תקשורת](20_satellite_communication.md) — תור FIFO, ניתוקים וקיבולת מוגבלת.
- [21. תחנת מזג אוויר](21_weather_station.md) — ממוצע נע, נתונים חסרים והשוואת כיסוי.
- [22. קופסה שחורה](22_black_box_logger.md) — זיכרון מעגלי ושחזור סדר כרונולוגי.
- [23. רובוט במחסן](23_warehouse_robot.md) — ניווט במפת רשימות ומלאי משותף.
- [24. מערכת ניטור מנועים](24_engine_monitor.md) — ניקוד סטיות, דירוג והשוואת צי.

## סדר הרמות

1. print ו-end
2. משתנים ופעולות חשבון
3. קלט והמרה
4. תנאים
5. לולאות עם תנאים ומשתני מצב
6. רשימות בלבד (כולל רשימות בתוך רשימות)
7. פעולות
8. מחלקות

## דרך העבודה

בכל רמה מנתחים קוד, מבצעים תרחיש שני, מנמקים החלטות וכותבים פתרון עצמאי.

את טבלאות המעקב בונים התלמידים בעצמם.

כל המספרים והמערכות הם מודלים דמיוניים לצורכי הוראה. אין להשתמש בקוד לתפעול, תכנון בטיחות או תחזוקה של מערכות אמיתיות.
