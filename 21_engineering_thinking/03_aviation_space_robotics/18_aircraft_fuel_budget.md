# ניהול דלק במטוס: איך בוחרים משימה בתוך תקציב מדומה?

במשחק סימולציה של משימות טיסה, כל משימה מניבה נקודות ודורשת תקציב משאבים.

אסור להשתמש בנקודות שנשמרו להחזרה ולתרחיש בלתי צפוי.

המטרה היא לבחור משימה אפשרית ובעלת ערך, ולא בהכרח משימה קצרה.

## כללי הסימולציה

כל המספרים הם נקודות משחק בדויות.

אין כאן חישוב דלק תעופתי, תכנון טיסה אמיתי או הוראות תפעול.

כל משימה בעלת עלות, עלות החזרה, רזרבה וניקוד.

אפשר לבצע משימה רק אם התקציב מכסה את שלושת המרכיבים.

במשחק, בחירה מבין חלופות חוקיות היא לפי ניקוד גבוה ביותר, אחר כך יתרה גדולה ביותר, ואז הראשונה ברשימה.

עלות ההחזרה והרזרבה נשמרות ולא נצרכות בסבב הניסוי.

**מטרת המשימה:** לבנות מערכת שלמה בהדרגה, לא רק להגיע לפלט נכון.

אפשר להתחיל ברמה המתאימה לחומר שנלמד.

אין צורך להכיר את הרמות הבאות.

בכל רמה יש ארבע משימות משנה, עם תרחיש מעקב נוסף, שאלות ביקורת ותכנון ניסויי בדיקה.

## רמה 6

**רשימות בלבד | קושי: מתקדמת**

שומרים נתוני חלופות ובודקים כיצד הבחירה משתנה עבור תקציבים שונים.

מותר רשימות, אינדקסים, len ו-append.

אין מילונים, סטים או טאפל.

אין def.

### 6.א קריאת קוד

```python
costs = [42, 35, 50, 20, 30, 32]
returns = [23, 22, 20, 15, 25, 23]
scores = [70, 70, 90, 35, 60, 60]
budgets = [50, 67, 75, 85]
choices = []
reserve = 10
for budget in budgets:
    best = -1
    best_margin = -1
    eligible = []
    margins = []
    for i in range(len(costs)):
        margin = budget - costs[i] - returns[i] - reserve
        margins.append(margin)
        if margin >= 0:
            eligible.append(i)
            if best == -1 or scores[i] > scores[best] or (scores[i] == scores[best] and margin > best_margin):
                best = i
                best_margin = margin
    choices.append(best)
    print(budget, eligible, margins)
    print("Choice:", best, best_margin)
print(choices)
```

כתבו את הפלט המדויק.

```python
def assess(budget, reserve, cost, back, score):
    if cost <= 0 or back < 0 or score < 0:
        return ["INVALID", -1]
    margin = budget - reserve - cost - back
    if margin < 0:
        return ["DENIED", margin]
    return ["OK", margin]

def select(costs, returns, scores, budget, reserve):
    if len(costs) != len(returns) or len(costs) != len(scores):
        return [-1, -1, -1]
    best = -1
    best_score = -1
    best_margin = -1
    for i in range(len(costs)):
        result = assess(budget, reserve, costs[i], returns[i], scores[i])
        if result[0] == "OK":
            margin = result[1]
            if best == -1 or scores[i] > best_score or (scores[i] == best_score and margin > best_margin):
                best = i
                best_score = scores[i]
                best_margin = margin
    return [best, best_score, best_margin]

print(assess(67, 10, 35, 22, 70))
print(assess(66, 10, 35, 22, 70))
print(select([42, 35, 50], [23, 22, 20], [70, 70, 90], 75, 10))
print(select([42, 35, 50], [23, 22, 20], [70, 70, 90], 80, 10))
```

```python
class Plan:
    def __init__(self, cost, back, score):
        self.cost = cost
        self.back = back
        self.score = score

    def margin(self, budget, reserve):
        return budget - self.cost - self.back - reserve

class Planner:
    def __init__(self, budget, reserve):
        self.budget = budget
        self.reserve = reserve
        self.selected = -1
        self.history = []

    def choose(self, plans):
        best = -1
        best_score = -1
        best_margin = -1
        for i in range(len(plans)):
            margin = plans[i].margin(self.budget, self.reserve)
            score = plans[i].score
            if margin >= 0:
                if best == -1 or score > best_score or (score == best_score and margin > best_margin):
                    best = i
                    best_score = score
                    best_margin = margin
        self.selected = best
        self.history.append(best)
        return [best, best_score, best_margin]

plans = [Plan(42, 23, 70), Plan(35, 22, 70), Plan(50, 20, 90)]
a = Planner(75, 10)
b = Planner(80, 10)
print(a.choose(plans))
print(b.choose(plans))
a.budget += 5
print(a.choose(plans))
print(a.history, b.history)
print(a.budget, b.budget)
```
