# קופסה שחורה: איך שומרים את האירועים האחרונים בזיכרון מוגבל?

במערכת סימולציה של תיעוד אירועים מתקבלות הודעות לפי סדר זמן.

הזיכרון מוגבל, אך מפעיל המעבדה צריך לדעת מה היה האירוע האחרון ומה היו האירועים האחרונים לפי הסדר.

אתם בונים רשם אירועים לימודי עם זיכרון מעגלי, לא מערכת תעופה אמיתית.

## כללי הסימולציה

זהו רשם אירועים בדוי שאינו משמש ציוד אמיתי.

קודי אירוע חוקיים 1–4.

קוד אחר נדחה ולא משנה את הרשומות.

קוד 4 מוגדר לצורך התרגיל כ-REVIEW.

הזיכרון שומר לכל היותר capacity אירועים חוקיים.

כשאין מקום, האירוע החדש מחליף את הישן ביותר.

ספירת האירועים החוקיים כוללת גם אירועים שכבר אינם בזיכרון.

הסדר המוצג בדוח הוא מהישן לחדש.

**מטרת המשימה:** לבנות מערכת שלמה בהדרגה, לא רק להגיע לפלט נכון.

אפשר להתחיל ברמה המתאימה לחומר שנלמד.

אין צורך להכיר את הרמות הבאות.

בכל רמה יש ארבע משימות משנה, עם תרחיש מעקב נוסף, שאלות ביקורת ותכנון ניסויי בדיקה.

אין להריץ את הקוד לפני מעקב ידני.

בחרו בעצמכם כיצד לבנות טבלת מעקב.

לא תינתן תבנית.

## רמה 6

**רשימות בלבד | קושי: מתקדמת**

מממשים זיכרון מעגלי באמצעות רשימה בלבד.

אינדקס next_slot מצביע לכתיבה הבאה.

אין מילונים, סטים או טאפל.

אין def.

### 6.א קריאת קוד

```python
events = [2, 4, 1, 3, 4, 0, 2, 1]
capacity = 4
memory = [0, 0, 0, 0]
next_slot = 0
stored = 0
accepted = 0
for code in events:
    if code >= 1 and code <= 4:
        memory[next_slot] = code
        next_slot = (next_slot + 1) % capacity
        accepted += 1
        if stored < capacity:
            stored += 1
    print(code, memory, next_slot, stored)
oldest = 0
if stored == capacity:
    oldest = next_slot
ordered = []
for i in range(stored):
    slot = (oldest + i) % capacity
    ordered.append(memory[slot])
print("Physical:", memory)
print("Ordered:", ordered)
print("Replaced:", accepted - stored)
```

כתבו את הפלט המדויק.

```python
class Recorder:
    def __init__(self, capacity):
        self.memory = []
        self.sequence = []
        for i in range(capacity):
            self.memory.append(0)
            self.sequence.append(0)
        self.next_slot = 0
        self.stored = 0
        self.accepted = 0
        self.invalid = 0

    def record(self, code):
        if code < 1 or code > 4:
            self.invalid += 1
            return False
        capacity = len(self.memory)
        self.accepted += 1
        self.memory[self.next_slot] = code
        self.sequence[self.next_slot] = self.accepted
        self.next_slot = (self.next_slot + 1) % capacity
        if self.stored < capacity:
            self.stored += 1
        return True

    def report(self):
        capacity = len(self.memory)
        oldest = 0
        if self.stored == capacity:
            oldest = self.next_slot
        codes = []
        numbers = []
        for i in range(self.stored):
            slot = (oldest + i) % capacity
            codes.append(self.memory[slot])
            numbers.append(self.sequence[slot])
        return [numbers, codes]

a = Recorder(3)
b = Recorder(5)
for code in [1, 4, 2, 0, 3, 4]:
    a.record(code)
    b.record(code)
print(a.report())
print(b.report())
print(a.accepted - a.stored, b.accepted - b.stored)
```
