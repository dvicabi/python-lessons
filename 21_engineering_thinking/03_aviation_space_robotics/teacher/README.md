בכל פתרון שמונה רמות, פלט מלא לשני התרחישים, תשובות לשאלות חשיבה ופתרון עצמאי אפשרי.

## בדיקות קוד

הריצו מתוך תיקיית המורה:

```bash
python verify_solutions.py
```

סקריפט הבדיקה מריץ 192 תרחישים: 64 קטעי קריאה, 64 תרחישים חלופיים ו-64 פתרונות כתיבה.

הבדיקה בוחנת גם התאמה לרמות הלימוד, סוגי מבני נתונים והקפדה על תנאי לולאה במקום פקודות יציאה ודילוג.

קובץ cases.json כולל את הקלטים, השינויים והפלטים הצפויים.

אתגרי התכנון הפתוחים דורשים הערכת מורה. הפתרונות במאגר ציבורי ואינם מוגנים בהרשאה.
