# מערכת ניטור מנועים: איך מזהים חריגות ובוחרים מה לבדוק קודם?

במעבדת נתונים יש כמה מנועים מדומים.

לכל אחד נקודת ייחוס שונה, ולכן אותו ערך מדידה לא בהכרח מצביע על אותה חריגה.

עליכם לחשב סטייה מנקודת ייחוס, לדרג רשומות ולהפיק דוח בדיקה.

לא כל ערך גבוה הוא נתון אמין.

## כללי הסימולציה

זהו מודל ציונים דמיוני בלבד, ללא יחידות פיזיקליות.

הוא אינו מערכת אבחון, בקרת מנוע או הוראות תחזוקה אמיתיות.

שני ערכים חוקיים בטווח 0–100, וגם נקודות הייחוס חוקיות.

ניקוד = הפרש חיובי ראשון + פי שניים ההפרש החיובי השני מנקודת הייחוס.

הפרש חיובי פירושו גודל הסטייה, גם כלפי מטה.

ניקוד 24 ומעלה CHECK, 12–23 WATCH, מתחת ל-12 NORMAL.

נתון בלתי חוקי INVALID, ללא ניקוד אמיתי.

בדירוג בוחרים תחילה רשומות חוקיות בעלות ניקוד גבוה, בשוויון את הראשונה.

דירוג אינו פעולת תחזוקה אלא סדר תצוגה במשחק.

**מטרת המשימה:** לבנות מערכת שלמה בהדרגה, לא רק להגיע לפלט נכון.

אפשר להתחיל ברמה המתאימה לחומר שנלמד.

אין צורך להכיר את הרמות הבאות.

בכל רמה יש ארבע משימות משנה, עם תרחיש מעקב נוסף, שאלות ביקורת ותכנון ניסויי בדיקה.

אין להריץ את הקוד לפני מעקב ידני.

בחרו בעצמכם כיצד לבנות טבלת מעקב.

לא תינתן תבנית.

```python
ref_b = 30
valid = 0
invalid = 0
checks = 0
transitions = 0
peak = -1
previous = "NONE"
for step in range(7):
    a = int(input())
    b = int(input())
    if a < 0 or a > 100 or b < 0 or b > 100:
        invalid += 1
        status = "INVALID"
        score = -1
    else:
        valid += 1
        da = a - ref_a
        db = b - ref_b
        if da < 0:
            da = -da
        if db < 0:
            db = -db
        score = da + db * 2
        if score >= 24:
            status = "CHECK"
            checks += 1
            if previous != "CHECK":
                transitions += 1
        elif score >= 12:
            status = "WATCH"
        else:
            status = "NORMAL"
        if score > peak:
            peak = score
    previous = status
    print(step + 1, status, score, peak)
print(valid, invalid, checks, transitions)
```

## רמה 6

**רשימות בלבד | קושי: מתקדמת**

משווים מנועים בעלי ייחוס שונה.

בונים רשימת ניקודים ואז בוחרים את שני הגבוהים החוקיים.

מותר רשימות, אינדקסים, len ו-append.

אין מילונים, סטים או טאפל.

אין def.

### 6.א קריאת קוד

```python
ref_a = [40, 50, 30, 70, 20, 45]
ref_b = [30, 40, 20, 50, 10, 30]
values_a = [48, 65, 35, 110, 25, 60]
values_b = [38, 45, 25, 52, 10, 35]
scores = []
for i in range(len(ref_a)):
    a = values_a[i]
    b = values_b[i]
    score = -1
    if a >= 0 and a <= 100 and b >= 0 and b <= 100:
        da = a - ref_a[i]
        db = b - ref_b[i]
        if da < 0:
            da = -da
        if db < 0:
            db = -db
        score = da + db * 2
    scores.append(score)
selected = []
for turn in range(2):
    best = -1
    for i in range(len(scores)):
        if scores[i] >= 0 and i not in selected:
            if best == -1 or scores[i] > scores[best]:
                best = i
    if best != -1:
        selected.append(best)
        print("Rank", turn + 1, best, scores[best])
print(scores)
print(selected)
```

```python
    if a < 0 or a > 100 or b < 0 or b > 100:
        return ["INVALID", -1]
    da = a - ref_a
    db = b - ref_b
    if da < 0:
        da = -da
    if db < 0:
        db = -db
    score = da + db * 2
    if score >= 24:
        return ["CHECK", score]
    if score >= 12:
        return ["WATCH", score]
    return ["NORMAL", score]

def top(scores, count):
    selected = []
    for turn in range(count):
        best = -1
        for i in range(len(scores)):
            if scores[i] >= 0 and i not in selected:
                if best == -1 or scores[i] > scores[best]:
                    best = i
        if best != -1:
            selected.append(best)
    return selected
```

```python
class Engine:
    def __init__(self, name, ref_a, ref_b):
        self.name = name
        self.ref_a = ref_a
        self.ref_b = ref_b
        self.scores = []
        self.statuses = []

    def measure(self, a, b):
        score = -1
        status = "INVALID"
        if a >= 0 and a <= 100 and b >= 0 and b <= 100:
            da = a - self.ref_a
            db = b - self.ref_b
            if da < 0:
                da = -da
            if db < 0:
                db = -db
            score = da + db * 2
            if score >= 24:
                status = "CHECK"
            elif score >= 12:
                status = "WATCH"
            else:
                status = "NORMAL"
        self.scores.append(score)
        self.statuses.append(status)
        return status

    def peak(self):
        highest = -1
        for score in self.scores:
            if score > highest:
                highest = score
        return highest

class Fleet:
    def __init__(self, engines):
        self.engines = engines

    def first_for_review(self):
        best = -1
        highest = -1
        for i in range(len(self.engines)):
            peak = self.engines[i].peak()
            if peak >= 24 and peak > highest:
                best = i
                highest = peak
        return best

b = Engine("B", 50, 40)

print(a.measure(101, 30), b.measure(50, 40))
fleet = Fleet([a, b])
print(a.scores, b.scores)
print(a.peak(), b.peak())
```
