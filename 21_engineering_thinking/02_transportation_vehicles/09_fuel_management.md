## רמה 7

**פעולות (פונקציות) | קושי: מתקדמת+**

### 7.א קריאת קוד

```python
def segment_cost(distance, rate):
    return distance * rate
def can_drive(fuel, cost, reserve):
    return cost > 0 and fuel - cost >= reserve
def route(distances, rates, fuel):
    history = []
    running = True
    index = 0
    while index < len(distances) and running:
        i = index
        index += 1
        cost = segment_cost(distances[i], rates[i])
        if not can_drive(fuel, cost, 3):
            running = False
        else:
            fuel -= cost
            history.append(fuel)
    return history
a = route([3, 5, 2, 4], [2, 3, 1, 2], 30)
b = route([3, 5, 2, 4], [2, 3, 1, 2], 40)
print(a)
print(b)
print(can_drive(15, 12, 3))
```

כתבו את הפלט המדויק.

בחרו שני רגעים שבהם שינוי משתנה משפיע על החלטה או חישוב מאוחר יותר.

### 8.א קריאת קוד

```python
class Vehicle:
    def __init__(self, fuel, reserve):
        self.fuel = fuel
        self.reserve = reserve
        self.distance = 0
        self.history = []

    def drive(self, length, rate):
        cost = length * rate
        if length <= 0 or rate <= 0 or self.fuel - cost < self.reserve:
            return False
        self.fuel -= cost
        self.distance += length
        self.history.append(self.fuel)
        return True

a = Vehicle(30, 3)
b = Vehicle(24, 5)
print(a.drive(5, 3))
print(b.drive(5, 3))
print(a.drive(4, 3))
print(b.drive(2, 3))
print(a.fuel, a.distance, a.history)
print(b.fuel, b.distance, b.history)
```
