# תחום 02: תחבורה ורכב

שמונה מערכות חדשות, משימות 9–16 במאגר.

בכל מערכת שמונה רמות מצטברות, מתחילת פייתון ועד מחלקות.

בכל רמה ארבע משימות משנה: קריאת קוד, תרחיש מעקב שני, ביקורת וחשיבה הנדסית, כתיבה עצמאית.

קטעי הקריאה ארוכים יותר מהתחום הראשון ומשלבים יותר משתנים, החלטות ומקרי גבול, בלי לדרוש חומר שטרם נלמד.
