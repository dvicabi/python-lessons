# תחנת רכבת: מדוע רכבת אחת מאחרת לכל הקו?

בתחנת רכבת יש לוח זמנים מתוכנן, אך איחור בתחנה אחת יכול לעבור לתחנות הבאות.

תפקידכם לנהל זמני הגעה, זמני שהייה וזמני יציאה באופן שמבדיל בין זמן מתוכנן לזמן בפועל.

## כללי הסימולציה

כל הזמנים הם דקות שלמות מאז תחילת יום סימולציה.

אין כאן לוח זמנים אמיתי.

רכבת לא יוצאת לפני הזמן המתוכנן;

היא ממתינה לפחות זמן שהייה מוגדר לאחר הגעתה.

זמן יציאה בפועל הוא הגדול מבין הזמן המתוכנן לבין ההגעה בתוספת שהייה.

איחור הוא יציאה בפועל פחות יציאה מתוכננת.

**מטרת המשימה:** לבנות מערכת שלמה בהדרגה, לא רק להגיע לפלט נכון.

אפשר להתחיל ברמה המתאימה לחומר שנלמד.

אין צורך להכיר את הרמות הבאות.

בכל רמה יש ארבע משימות משנה.

אין להריץ את הקוד לפני מעקב ידני.

בחרו בעצמכם כיצד לבנות טבלת מעקב.

לא תינתן תבנית.

## רמה 7

**פעולות (פונקציות) | קושי: מתקדמת+**

פעולה אחת מחשבת יציאה, פעולה נוספת משתמשת בה בכל התחנות.

החזירו ערך יחיד או רשימה בלבד.

### 7.א קריאת קוד

```python
def departure(arrival, dwell, planned):
    earliest = arrival + dwell
    if earliest < planned:
        return planned
    return earliest

def line(travels, plans, start):
    actual = start
    delays = []
    for i in range(len(travels)):
        actual = departure(actual + travels[i], 2, plans[i])
        delays.append(actual - plans[i])
    return delays

print(departure(107, 2, 112))
print(departure(125, 2, 125))
print(line([7, 13, 8, 12], [112, 125, 140, 152], 100))
print(line([7, 13, 8, 12], [112, 125, 140, 152], 105))
```

class Train:
    def __init__(self, start):
        self.actual = start
        self.delays = []
        self.total_wait = 0

    def station(self, travel, dwell, planned):
        earliest = self.actual + travel + dwell
        if earliest < planned:
            self.total_wait += planned - earliest
            self.actual = planned
        else:
            self.actual = earliest
        delay = self.actual - planned
        self.delays.append(delay)
        return delay

a = Train(100)
b = Train(105)
print(a.station(7, 2, 112))
print(b.station(7, 2, 112))
print(a.station(13, 2, 125))
print(b.station(13, 2, 125))
print(a.station(8, 2, 140))
print(b.station(8, 2, 140))
print(a.actual, a.total_wait, a.delays)
