בכל רמה פלט מדויק לשני תרחישי הקריאה, תשובות לחשיבה ופתרון אפשרי לכתיבה העצמאית.

התלמידים בונים את טבלאות המעקב בעצמם.

## בדיקות

הריצו מתוך תיקיית המורה:

```bash
python verify_solutions.py
```

הסקריפט בודק התאמה לרמות הלימוד באמצעות AST ומריץ 192 תרחישים בפייתון: 64 דוגמאות מקוריות, 64 תרחישים לאחר שינוי, 64 פתרונות כתיבה.

קובץ cases.json כולל את הקלטים, השינויים והפלטים הצפויים.

מקרי בדיקה פתוחים שהמציאו תלמידים ואתגרי ההרחבה דורשים הערכת מורה.

המאגר ציבורי. הפתרונות אינם מוגנים בהרשאה.
