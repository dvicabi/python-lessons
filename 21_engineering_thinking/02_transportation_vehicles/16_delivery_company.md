# חברת משלוחים: מי צריך לקבל את החבילה קודם?

חברת משלוחים מקבלת חבילות רבות, אך לכל רכב יש מגבלת משקל וזמן.

לא תמיד ניתן לקחת את כל החבילות, ולקוחות דחופים צריכים לקבל עדיפות.

אתם מפתחים מנגנון שקולט דרישות, בודק אם הן אפשריות ומחליט איזה משלוח לבצע הבא.

## כללי הסימולציה

כל נתוני המשקל והזמן בדויים.

כל משלוח צורך משקל וקבוע זמן (משך ביצוע), ואין הורדת חבילות או חזרה למחסן במהלך סבב מדומה.

מספר עדיפות קטן מציין דחיפות גבוהה יותר.

בגרסה המתקדמת בוחרים בכל פעם את המשלוח האפשרי בעל העדיפות הקטנה ביותר;

בשוויון משך קצר יותר, ואז ההזמנה שהופיעה ראשונה.

אין לחרוג ממשקל או מזמן פנויים.

משקל ומשך משלוח חיוביים;

אפשר להשלים סבב עם משאבים שנותרו.

**מטרת המשימה:** לבנות מערכת שלמה בהדרגה, לא רק להגיע לפלט נכון.

אפשר להתחיל ברמה המתאימה לחומר שנלמד.

אין צורך להכיר את הרמות הבאות.

בכל רמה יש ארבע משימות משנה.

אין להריץ את הקוד לפני מעקב ידני.

בחרו בעצמכם כיצד לבנות טבלת מעקב.

לא תינתן תבנית.

### 6.א קריאת קוד

```python
weights = [6, 5, 4, 3, 2]
durations = [12, 18, 10, 8, 6]
priorities = [2, 1, 1, 2, 1]
weight_left = 12
time_left = 30
selected = []
while True:
    best = -1
    for i in range(len(weights)):
        if i in selected:
            continue
        if weights[i] > weight_left or durations[i] > time_left:
            continue
        if best == -1 or priorities[i] < priorities[best] or (priorities[i] == priorities[best] and durations[i] < durations[best]):
            best = i
    if best == -1:
        break
    selected.append(best)
    weight_left -= weights[best]
    time_left -= durations[best]
    print(best, weight_left, time_left)
print(selected)
```

```python
def plan(weights, durations, priorities, w, t):
    selected = []
    while True:
        i = choose(weights, durations, priorities, selected, w, t)
        if i == -1:
            return selected
        selected.append(i)
        w -= weights[i]
        t -= durations[i]

weights = [6, 5, 4, 3, 2]
durations = [12, 18, 10, 8, 6]
priorities = [2, 1, 1, 2, 1]
print(plan(weights, durations, priorities, 12, 30))
print(plan(weights, durations, priorities, 12, 34))
print(plan(weights, durations, priorities, 1, 30))
```

```python
class Truck:
    def __init__(self, weight, time):
        self.weight = weight
        self.time = time
        self.assigned = []

    def can_take(self, weight, duration):
        return weight > 0 and duration > 0 and weight <= self.weight and duration <= self.time

    def take(self, order, weight, duration):
        if order in self.assigned or not self.can_take(weight, duration):
            return False
        self.weight -= weight
        self.time -= duration
        self.assigned.append(order)
        return True

a = Truck(12, 30)
b = Truck(8, 25)
print(a.take(104, 5, 18))
print(b.take(107, 4, 10))
print(a.take(108, 4, 15))
print(a.take(104, 1, 1))
print(b.take(109, 4, 15))
print(a.weight, a.time, a.assigned)
print(b.weight, b.time, b.assigned)
```
