לכל מערכת שמונה רמות, ובכל רמה פלט מדויק לשני תרחישי המעקב, תשובות לשאלות חשיבה ופתרון עצמאי אפשרי.

## בדיקות קוד

הריצו מתוך תיקיית המורה:

```bash
python verify_solutions.py
```

הסקריפט מיועד להריץ 192 תרחישים בפייתון: 64 קטעי קריאה, 64 תרחישים חלופיים ו-64 פתרונות כתיבה.

הוא בודק גם התאמת תחביר לרמת הלימוד ומגבלות השפה.

קובץ cases.json כולל קלטים, שינויים ופלטים צפויים. אתגרי התכנון הפתוחים דורשים בדיקה והערכת מורה.

הפתרונות נמצאים במאגר ציבורי ואינם מוגנים בהרשאה. כל הדוגמאות הן נתוני תרגול, לא סיסמאות או תשתיות אמיתיות.
