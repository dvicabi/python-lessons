## רמה 8

**מחלקות | קושי: אתגר מסכם**

כל בקר מחזיק תקלה ומצב משלו; איפוס הוא פעולה מפורשת.

מותר להגדיר class, __init__, self ופעולות של אובייקט. ממשיכים להשתמש ברשימות בלבד כמבנה נתונים.

### 8.א קריאת קוד

```python
class Heater:
    def __init__(self):
        self.on = False
        self.fault = False

    def measure(self, value):
        if value < 0 or value > 80:
            self.fault = True
        if self.fault:
            self.on = False
        elif value <= 45:
            self.on = True
        elif value >= 50:
            self.on = False

a = Heater()
b = Heater()
a.measure(90)
a.measure(42)
b.measure(42)
print(a.on, a.fault)
print(b.on, b.fault)
```

1. הכינו טבלת מעקב בעצמכם וכתבו את הפלט המדויק.

2. למה מדידה חוקית אינה מספיקה להחלמה של a?

### 8.ב שינוי וחשיבה

החליפו a.measure(90) ב-a.measure(80) בקוד הנתון. מה ישתנה?

הכינו טבלת מעקב גם לגרסה ששיניתם. הסבירו איזה כלל צריך להישמר כדי שלא יוצג מצב שגוי.

### 8.ג כתיבה עצמאית

הוסיפו reset() שמכבה ומנקה fault. שמרו גם active מצטבר שאינו נמחק באיפוס. צרו a ו-b; a מקבל 44,90,42 ואז reset ו-43; b מקבל 48. הדפיסו on,fault,active לכל אחד.

כתבו תחילה את סדר הפעולות במילים, אחר כך את הקוד. הציגו פלט ברור באנגלית. בחרו ערך נוסף לבדיקה, חזו את התוצאה ובדקו בפועל.
