# פתרונות למורה

שמונה קובצי פתרונות מקבילים, כל אחד לפי שמונה רמות הלימוד. לכל רמה פלט מדויק, תשובה לשאלת החשיבה, הסבר לשינוי ופתרון אפשרי לכתיבה העצמאית. את טבלאות המעקב התלמידים מתכננים בעצמם.

## בדיקת הדוגמאות

מתוך תיקיית המורה:

```bash
python verify_solutions.py
```

הבדיקה מריצה את 64 קטעי הקריאה ו-64 פתרונות הכתיבה בפייתון, ומשווה את הפלט לערכים בקובצי הבדיקות. שאלות שינוי פתוחות ואתגרי ההרחבה דורשים הערכה אנושית.

המאגר ציבורי; מומלץ לשתף תלמידים בקישור לקובץ המשימה בלבד. אין צורך להתקין חבילות נוספות.
