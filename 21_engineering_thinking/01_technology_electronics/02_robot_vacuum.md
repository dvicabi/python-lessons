## רמה 8

**מחלקות | קושי: אתגר מסכם**

נבנה מחלקה שמנהלת את מיקום הרובוט, סוללתו והיסטוריית הניקיון.

מותר להגדיר class, __init__, self ופעולות של אובייקט. ממשיכים להשתמש ברשימות בלבד כמבנה נתונים.

### 8.א קריאת קוד

```python
class Robot:
    def __init__(self, battery):
        self.position = 0
        self.battery = battery
        self.visited = [0]

    def move(self, direction):
        if direction != 1 and direction != -1:
            return
        if self.battery < 2:
            return
        candidate = self.position + direction
        if candidate < 0 or candidate > 5 or candidate == 3:
            self.battery -= 1
        else:
            self.position = candidate
            self.battery -= 2
            if candidate not in self.visited:
                self.visited.append(candidate)

a = Robot(6)
b = Robot(3)
a.move(1)
a.move(1)
b.move(-1)
print(a.visited, a.battery)
print(b.visited, b.battery)
```

1. הכינו טבלת מעקב בעצמכם וכתבו את הפלט המדויק.

2. למה הרשימה חייבת להיווצר בתוך __init__ לכל אובייקט בנפרד?

### 8.ב שינוי וחשיבה

בקוד הנתון הוסיפו a.move(1) אחרי שתי תנועות a. מה השינוי במצב a ו-b?

הכינו טבלת מעקב גם לגרסה ששיניתם. הסבירו איזה כלל צריך להישמר כדי שלא יוצג מצב שגוי.

### 8.ג כתיבה עצמאית

הרחיבו את Robot הקיימת, כולל רשימת visited ובדיקת כיוון חוקי, עם charge(amount) שמותרת רק בתא 0, מקבלת כמות חיובית ומגבילה סוללה ל-10. צרו שני רובוטים בסוללה 4. הזיזו a ימינה, נסו להטעין אותו ב-8, הטעינו b ב-8. הדפיסו מיקום וסוללה של כל אחד.

כתבו תחילה את סדר הפעולות במילים, אחר כך את הקוד. הציגו פלט ברור באנגלית. בחרו ערך נוסף לבדיקה, חזו את התוצאה ובדקו בפועל.
