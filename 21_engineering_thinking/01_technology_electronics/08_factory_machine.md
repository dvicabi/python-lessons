## רמה 8

**מחלקות | קושי: אתגר מסכם**

ממשיכים להשתמש ברשימות בלבד כמבנה נתונים.

### 8.א קריאת קוד

```python
class Monitor:
    def __init__(self):
        self.streak = 0
        self.stopped = False

    def measure(self, value):
        if self.stopped:
            return
        if value >= 90 or value < 0 or value > 100:
            self.stopped = True
        elif value >= 75:
            self.streak += 1
            if self.streak >= 3:
                self.stopped = True
        else:
            self.streak = 0

a = Monitor()
b = Monitor()
a.measure(75)
a.measure(80)
a.measure(76)
b.measure(80)
a.measure(40)
print(a.streak, a.stopped)
print(b.streak, b.stopped)
```

1. הכינו טבלת מעקב בעצמכם וכתבו את הפלט המדויק.

2. מדוע a.measure(40) אינה מאפסת את הרצף?

### 8.ב שינוי וחשיבה

בקוד הנתון שנו את a.measure(76) ל-a.measure(60).

מה יקרה למדידה האחרונה?

הכינו טבלת מעקב גם לגרסה ששיניתם.

הסבירו איזה כלל צריך להישמר כדי שלא יוצג מצב שגוי.

### 8.ג כתיבה עצמאית

הוסיפו reason ו-reset.

INVALID קודם ל-CRITICAL, אחריו STREAK;

reason נשמר בעת עצירה ואחרי reset נהיה NONE.

התחילו a,b.

הזינו a מדידות 75,101,70;

b מדידות 75,75.

הדפיסו לכל אחד streak,stopped,reason.

אפסו a והדפיסו את המצב החדש.

כתבו תחילה את סדר הפעולות במילים, אחר כך את הקוד.
