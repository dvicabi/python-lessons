# תחום 01: מערכות טכנולוגיות ואלקטרוניקה

שמונה מערכות.

לכל אחת שמונה רמות הדרגתיות (64 בסך הכול), ובכל רמה שלוש משימות משנה: ניתוח קוד, שינוי וחשיבה, כתיבה עצמאית.

בנוסף שמונה אתגרי הרחבה מסכמים.

## סדר הרמות

1. print ו-end
2. משתנים וחשבון
3. קלט
4. תנאים
5. לולאות
6. רשימות
7. פעולות
8. מחלקות

אין צורך לדעת מראש את כל הנושאים.

בוחרים את המערכת ואת הרמה לפי קצב הכיתה.

בכל רמה יש לקרוא ולהבין לפני הרצה, להכין טבלת מעקב עצמאית כשיש משתנים, לחשוב על שינוי ולכתוב קוד חדש.

בכיתה אפשר לפצל רמה למספר חלקי שיעור.
