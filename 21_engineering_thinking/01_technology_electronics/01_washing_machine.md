# מכונת כביסה: מי מנהל את מחזור הכביסה?

אתם צוות הפיתוח של מכונת כביסה. לקוח רוצה לדעת מתי מתחיל מילוי, מתי מתחילה שטיפה ומתי המכונה מוכנה לסיום. תבנו תוכנה בהדרגה, מהצגת המצב עד לניהול מכונות שונות.

המודל לימודי: כמויות המים הן יחידות דמיוניות. אין לחבר תוכנה לחומרה. בשלבים הראשונים מדמים מילוי בלבד; במחלקה מוסיפים מעבר שלב.

**המטרה:** לעבור בהדרגה מתצוגה פשוטה לתוכנה שאפשר להרחיב ולבדוק. כל רמה מתפתחת מהרמה הקודמת. מתחילים ברמה המתאימה לחומר שנלמד; אין צורך להכיר את הרמות הבאות.

## רמה 8

**מחלקות | קושי: אתגר מסכם**

כל מכונה זוכרת את כמות המים והמצב שלה בנפרד. מילוי אחרי WASH אינו מותר.

מותר להגדיר class, __init__, self ופעולות של אובייקט. ממשיכים להשתמש ברשימות בלבד כמבנה נתונים.

### 8.א קריאת קוד

```python
class Washer:
    def __init__(self, target):
        self.target = target
        self.water = 0
        self.stage = "FILL"

    def fill(self, added):
        if self.stage == "FILL" and added >= 0:
            self.water += added
            if self.water >= self.target:
                self.water = self.target
                self.stage = "WASH"

a = Washer(6)
b = Washer(4)
a.fill(5)
b.fill(7)
a.fill(3)
b.fill(2)
print(a.water, a.stage)
print(b.water, b.stage)
```

1. הכינו טבלת מעקב בעצמכם וכתבו את הפלט המדויק.

2. איזו מכונה מושפעת מ-b.fill(7)? מדוע מילוי נוסף לא משנה אותה?

### 8.ב שינוי וחשיבה

שנו את b.fill(7) ל-b.fill(2) בקוד הנתון. עקבו אחרי שתי המכונות.

הכינו טבלת מעקב גם לגרסה ששיניתם. הסבירו איזה כלל צריך להישמר כדי שלא יוצג מצב שגוי.

### 8.ג כתיבה עצמאית

הרחיבו את Washer עם reset() שמחזירה את המכונה ל-FILL ול-0 מים בלי לשנות יעד. צרו a עם יעד 6, b עם יעד 4. מלאו a ב-5, b ב-4, אפסו רק b ומלאו בה 1. הדפיסו מצב שתי המכונות.

כתבו תחילה את סדר הפעולות במילים, אחר כך את הקוד. הציגו פלט ברור באנגלית. בחרו ערך נוסף לבדיקה, חזו את התוצאה ובדקו בפועל.
