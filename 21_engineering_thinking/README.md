# מעבדת חשיבה הנדסית בפייתון

מאגר משימות לתלמידי תיכון: בכל מערכת מתחילים בבעיה ממשית, ומתקדמים בהדרגה מהצגת מידע עד תכנון מערכת מלאה.

אפשר לעצור בכל שלב בהתאם לחומר שנלמד בכיתה.

## רצף הלימוד בכל מערכת

1. print ו-end
2. משתנים וחשבון
3. קלט
4. תנאים
5. לולאות
6. רשימות
7. פעולות
8. מחלקות

בכל רמה לפחות שלוש משימות משנה: קריאת קוד ומעקב, שינוי וחשיבה, כתיבה עצמאית ובדיקה.

מהתחום השני יש ארבע משימות משנה בכל רמה, עם שני תרחישי מעקב נפרדים ושאלות ביקורת הנדסית מעמיקות.

לאחר רמה 8 יש אתגר הנדסי משלב.

התלמידים בונים טבלאות מעקב בעצמם, ללא תבנית מוכנה.

מבנה הנתונים היחיד שנלמד במסלול זה הוא רשימה.
