בכל קובץ שמונה רמות, עם פלט לשני תרחישי קריאה, תשובות מנומקות ופתרון אפשרי לכתיבה העצמאית.

משימות הניסוי והאתגרים המסכמים פתוחים; יש להעריך את התחזית, הקוד, הפלט והנימוק ולא להסתפק בהשוואת תוצאה אחת.

## בדיקות קוד

מתוך תיקיית המורה:

```bash
python verify_solutions.py
```

הסקריפט מיועד לבדוק 192 תרחישים בפייתון: 64 דוגמאות מקוריות, 64 תרחישים חלופיים ו-64 פתרונות עצמאיים.

הבדיקה כוללת התאמה לרמות הלימוד, תחביר ופלט.

קובץ cases.json מכיל קלטים, שינויים ופלטים צפויים.

הפתרונות נמצאים במאגר ציבורי.
