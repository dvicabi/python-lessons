# תחום 05: מערכות מהחיים

שמונה מערכות, משימות 33–40 במאגר.

בכל מערכת שמונה רמות מצטברות, עם חמש משימות משנה בכל רמה.

64 רמות ו-320 משימות משנה, ועוד שמונה אתגרי תכנון מסכמים.

קטעי הקריאה מגיעים עד 82 שורות קוד, עם דגש על חיפוש הרכב מיטבי, בחירת חלופות, מאזני משאבים, שוברי שוויון, אחריות בין מחלקות ובדיקת תקינות לאחר שינוי.

## המשימות

- [33. כספומט](33_atm.md) — חיפוש הרכב שטרות ומאזן כספת וחשבון.
- [34. קופה בסופר](34_supermarket_checkout.md) — איחוד שורות, מבצעים, מלאי ומניעת חיוב כפול.
- [35. מכונת חטיפים](35_vending_machine.md) — חיפוש עודף, כשל מסירה והחזר.
- [36. משחק כדורגל](36_football_league.md) — טבלת ליגה, שוברי שוויון ויומן משחקים.
- [37. מסעדה](37_restaurant.md) — שיבוץ קבוצות, התאמת קיבולת ומאזן אורחים.
- [38. לונה פארק](38_amusement_park.md) — תורים, קיבולת והוגנות ללא פיצול.
- [39. משחק מחשב](39_computer_game.md) — מעברי מצב, ניהול שחקנים ודירוג.
- [40. בית קולנוע](40_cinema.md) — חיפוש רצפים במפה דו-ממדית, הזמנות וביטול.

## סדר הלימוד

## דרך העבודה

א. מנתחים קוד וכותבים תחזית לפלט.

ב. עוקבים אחר תרחיש נוסף ובודקים איזה שינוי גרם להבדל.

ג. מנמקים את ההחלטות ומבקרים את הקוד.

ד. כותבים פתרון עצמאי.

ה. מתכננים ניסוי חדש, כולל מקרה גבול, תחזית והסבר.

התלמידים מגדירים בעצמם את טבלאות המעקב.

כל הנתונים מדומים לצורכי לימוד, ללא חיבור לבנקים, מערכות תשלום, מתקנים, אתרי הזמנות או שירותים אמיתיים.
