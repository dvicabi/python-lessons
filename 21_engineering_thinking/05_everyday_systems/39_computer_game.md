# משחק מחשב: איך מנהלים חיים, אנרגיה ועליית רמות?

במשחק מדומה דמות מבצעת משימות, מתאוששת ומתמודדת עם מכשולים.

עדכון אחד יכול להשפיע על כמה מדדים, ולא כל פעולה מותרת בכל מצב.

תפתחו מנגנון שמבדיל בין חוקי המשחק לבין תצוגת המצב, ומאפשר לכמה שחקנים להתקדם באופן עצמאי.

## כללי הסימולציה

כל המדדים דמיוניים.

חיים 0–100, אנרגיה 0–20, ניסיון XP לא שלילי, רמה 1+XP//10.

פעולה 1 היא אימון: עולה 4 אנרגיה ומוסיפה 7 XP.

פעולה 2 היא מנוחה: מוסיפה 5 אנרגיה עד 20.

פעולה 3 היא מכשול: מורידה 30 חיים עד 0.

פעולה 4 היא ריפוי: עולה 3 אנרגיה ומוסיפה 20 חיים עד 100.

אימון וריפוי נדחים אם אין די אנרגיה.

כשחיים 0, כל פעולה מוכרת נדחית עם FINISHED.

פעולה לא מוכרת INVALID גם במצב סיום.

אין שינוי באירוע שנדחה.

ברמות 2–3 החישובים ידועים מראש וללא הגבלות אוטומטיות.

**מטרת המשימה:** לבנות מערכת שלמה בהדרגה, לא רק להגיע לפלט נכון.

אפשר להתחיל ברמה המתאימה לחומר שנלמד.

אין צורך להכיר את הרמות הבאות.

בכל רמה יש חמש משימות משנה: שני מעקבים, שאלות ביקורת, כתיבה עצמאית וניסוי הנדסי.

אין להריץ את הקוד לפני מעקב ידני.

בחרו בעצמכם כיצד לבנות טבלת מעקב.

לא תינתן תבנית.

```text

```

```python
health = 60
energy = 10
xp = 0
level = 1
ok = 0
denied = 0
level_ups = 0
for i in range(10):
    action = int(input())
    status = "OK"
    if action < 1 or action > 4:
        status = "INVALID"
    elif health == 0:
        status = "FINISHED"
    elif action == 1:
        if energy < 4:
            status = "LOW"
        else:
            energy -= 4
            xp += 7
    elif action == 2:
        energy += 5
        if energy > 20:
            energy = 20
    elif action == 3:
        health -= 30
        if health < 0:
            health = 0
    elif energy < 3:
        status = "LOW"
    else:
        energy -= 3
        health += 20
        if health > 100:
            health = 100
    next_level = 1 + xp // 10
    level_ups += next_level - level
    level = next_level
    if status == "OK":
        ok += 1
    else:
        denied += 1
    print(i + 1, status, health, energy, xp, level)
print(ok, denied, level_ups)
print("Check:", ok + denied)
```

```python
def apply(state, action):
    health = state[0]
    energy = state[1]
    xp = state[2]
    status = "OK"
    if action < 1 or action > 4:
        status = "INVALID"
    elif health == 0:
        status = "FINISHED"
    elif action == 1:
        if energy >= 4:
            energy -= 4
            xp += 7
        else:
            status = "LOW"
    elif action == 2:
        energy += 5
        if energy > 20:
            energy = 20
    elif action == 3:
        health -= 30
        if health < 0:
            health = 0
    elif energy >= 3:
        energy -= 3
        health += 20
        if health > 100:
            health = 100
    else:
        status = "LOW"
    return [[health, energy, xp], status]

def simulate(state, actions):
    history = []
    for action in actions:
        result = apply(state, action)
        state = result[0]
        history.append(result[1])
    return [state, history]

start = [60, 4, 8]
print(apply(start, 1))
print(simulate(start, [1, 1, 2, 1]))
print(simulate(start, [2, 1, 1, 1]))
print(start)
```

### 8.א קריאת קוד

```python
class Player:
    def __init__(self, name, health, energy):
        self.name = name
        self.health = health
        self.energy = energy
        self.xp = 0

    def act(self, action):
        if action < 1 or action > 4:
            return "INVALID"
        if self.health == 0:
            return "FINISHED"
        if action == 1:
            if self.energy < 4:
                return "LOW"
            self.energy -= 4
            self.xp += 7
        elif action == 2:
            self.energy += 5
            if self.energy > 20:
                self.energy = 20
        elif action == 3:
            self.health -= 30
            if self.health < 0:
                self.health = 0
        elif self.energy < 3:
            return "LOW"
        else:
            self.energy -= 3
            self.health += 20
            if self.health > 100:
                self.health = 100
        return "OK"

    def report(self):
        level = 1 + self.xp // 10
        return [self.name, self.health, self.energy, self.xp, level]

class Arena:
    def __init__(self, players):
        self.players = players
        self.history = []

    def event(self, index, action):
        if index < 0 or index >= len(self.players):
            status = "UNKNOWN"
        else:
            status = self.players[index].act(action)
        self.history.append([index, action, status])
        return status

    def better(self, i, best):
        if best == -1:
            return True
        a = self.players[i]
        b = self.players[best]
        if a.xp != b.xp:
            return a.xp > b.xp
        return a.health > b.health

    def rank(self):
        result = []
        for turn in range(len(self.players)):
            best = -1
            for i in range(len(self.players)):
                if i not in result and self.better(i, best):
                    best = i
            result.append(best)
        return result

    def reports(self):
        result = []
        for player in self.players:
            result.append(player.report())
        return result

a = Player("A", 60, 8)
b = Player("B", 100, 4)
arena = Arena([a, b])
for event in [[0, 1], [1, 1], [0, 1], [1, 2], [1, 1], [0, 3], [0, 3], [0, 2], [2, 1]]:
    print(arena.event(event[0], event[1]))
print(arena.reports())
print(arena.rank())
print(arena.history)
```
