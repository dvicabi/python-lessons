## איך מעבירים את השיעור?

כל משימה מיועדת לקבוצה של שלושה תלמידים. אם יש ארבעה, התלמיד הרביעי אחראי לרישום הבדיקות וההחלטות של הקבוצה.

בתחילת השיעור נותנים לכל תלמיד רק את החלק שלו (מעתיקים או מדפיסים בנפרד). לא שולחים בשלב הזה את הקובץ המלא, כי הוא מכיל את כל החלקים.

- תלמיד א מקבל את הדרישות.
- תלמיד ב מקבל קוד שצריך לבדוק ולתקן.
- תלמיד ג מקבל את מקרי הבדיקה.

אחרי חמש דקות של עבודה אישית, כל תלמיד מסביר לקבוצה את החלק שלו. לאחר מכן התלמידים בונים ביחד את הפתרון.

במהלך העבודה מחליפים תפקידים. כל אחד צריך לדעת להסביר את הקוד ולא רק את החלק שהוא עשה.

לקראת סוף השיעור בודקים את התוכנית. אם יש זמן, מעבירים בדיקה אחת לקבוצה אחרת.

## שאלות לסוף השיעור

כל תלמיד עונה בעצמו:

1. מה עשיתי בקבוצה?
2. מה הבנתי בזכות אחד מחברי הקבוצה?
3. האם היה שלב שמישהו עשה בו את רוב העבודה לבד?
4. מה היה פחות טוב ומה הייתי משנה בפעם הבאה?

התשובות יעזרו לי להבין איך לחלק את הקבוצות והתפקידים בשיעור הבא.

המשימות הן לתרגול תכנות בלבד ולא להפעלה של ציוד אמיתי.
